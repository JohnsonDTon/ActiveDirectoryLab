Review and change the settings based on your environment and intentions. </br></br>

Create static IP Address for VM (skip if using DHCP). <br>
Default-gateway not included since AD labs are done via internal switch first. Add -DefaultGateway "192.168.100.1" line if you configured gateway already (OPNsense) and you want your lab to be connected to internet. See 'Set up OPNsense (OPNSENSE01).md'<br>
This assumes you see 'Ethernet' when you run Get-NetAdapter as its the default.
```powershell
Remove-NetRoute -InterfaceAlias "Ethernet" -DestinationPrefix "0.0.0.0/0" -Confirm:$false
Set-NetIPInterface -InterfaceAlias "Ethernet" -Dhcp Disabled
Remove-NetIPAddress -InterfaceAlias "Ethernet" -AddressFamily IPv4 -Confirm:$false
```
```powershell
New-NetIPAddress `
    -InterfaceAlias "Ethernet" `
    -IPAddress "192.168.100.10" `
    -PrefixLength 24
```
<br>

Configure DNS settings
```powershell
Set-DnsClientServerAddress `
    -InterfaceAlias "Ethernet" `
    -ServerAddresses "192.168.100.10, 192.168.100.11"
```
<br>

Verify
```powershell
ipconfig /all
```
