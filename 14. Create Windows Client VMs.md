I will build 3 Windows 11 VMs WIN11-01 and WIN11-02.<br>

Follow Create VM.md but with Windows 11 Pro OS<br>
https://github.com/JohnsonDTon/ActiveDirectoryLab/blob/main/03.%20Create%20VM.md <br>
Make sure the IP/DNS is configured <br>
Reference: https://github.com/JohnsonDTon/ActiveDirectoryLab/blob/main/04.%20Configure%20IP.md <br>

Join domain. Run on Client VM.
```powershell
Add-Computer `
    -DomainName "adlab.test" `
    -Credential "ADLAB\Administrator" `
    -Restart
```

Move Client VM to correct OU. Run on DC.
```powershell
$WIN1101 = Get-ADComputer "WIN11-01"

Move-ADObject `
    -Identity $WIN1101.DistinguishedName `
    -TargetPath "OU=IT,OU=Workstations,DC=adlab,DC=test"
```

Verify.
```powershell
Get-ADComputer "WIN11-01" |
    Select-Object Name, DistinguishedName
```
