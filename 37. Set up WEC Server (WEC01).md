Run this on a fresh (and named) Windows Server VM that you'd making it to be your WEC Server. (refer to Create Windows VM.md) <br>
Make sure the IP/DNS is configured. (refer to Configure IP.md)

Join server to domain
```powershell
Add-Computer `
    -DomainName "adlab.test" `
    -Credential "ADLAB\Administrator" `
    -Restart
```

Move server to correct OU. Run on DC.
```powershell
Move-ADObject `
    -Identity "CN=WEC01,CN=Computers,DC=adlab,DC=test" `
    -TargetPath "OU=Member Servers,OU=Servers,DC=adlab,DC=test"
```
