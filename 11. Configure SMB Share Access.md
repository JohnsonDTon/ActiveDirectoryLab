This assumes you have configured File Server (FILE01) and your NTFS layer permissions already. <br>
Run everything on FILE01 <br> <br>

Our design approach is Broad SMB + Granular NTFS, as this is common approach in enterprise enviornments. <br>
We want to do something like this.
```text
IT
SMB  → Authenticated Users → Full Control
NTFS → DL-FILE01-IT-Modify → Modify

HR
SMB  → Authenticated Users → Full Control
NTFS → DL-FILE01-HR-Modify → Modify

Finance
SMB  → Authenticated Users → Full Control
NTFS → DL-FILE01-Finance-Modify → Modify

Public
SMB  → Authenticated Users → Full Control
NTFS → DL-FILE01-Public-Read → Read & Execute
```

Create the SMB Shares
```powershell
New-SmbShare `
    -Name "IT" `
    -Path "E:\Shares\IT"

New-SmbShare `
    -Name "HR" `
    -Path "E:\Shares\HR"

New-SmbShare `
    -Name "Finance" `
    -Path "E:\Shares\Finance"

New-SmbShare `
    -Name "Public" `
    -Path "E:\Shares\Public"
```

Verify SMB Shares are created
```powershell
Get-SmbShare |
    Where-Object Name -in "IT","HR","Finance","Public" |
    Select-Object Name, Path, Description
```

Grant Authenticated Users Full Control at the SMB Layer
```powershell
Grant-SmbShareAccess `
    -Name "IT" `
    -AccountName "Authenticated Users" `
    -AccessRight Full `
    -Force

Grant-SmbShareAccess `
    -Name "HR" `
    -AccountName "Authenticated Users" `
    -AccessRight Full `
    -Force

Grant-SmbShareAccess `
    -Name "Finance" `
    -AccountName "Authenticated Users" `
    -AccessRight Full `
    -Force

Grant-SmbShareAccess `
    -Name "Public" `
    -AccountName "Authenticated Users" `
    -AccessRight Full `
    -Force
```

Revoke access for 'Everyone'. <br>
This was given by default when we created the SMBshares.
```powershell
$Shares = @(
    "IT",
    "HR",
    "Finance",
    "Public"
)

foreach ($Share in $Shares) {
    Revoke-SmbShareAccess `
        -Name $Share `
        -AccountName "Everyone" `
        -Force
}
```

Verify access at SMB level.
It should only be Full Access rights for 'NT AUTHORITY\Authenticated Users' only.
```powershell
Get-SmbShareAccess -Name "IT"
Get-SmbShareAccess -Name "HR"
Get-SmbShareAccess -Name "Finance"
Get-SmbShareAccess -Name "Public"
```
