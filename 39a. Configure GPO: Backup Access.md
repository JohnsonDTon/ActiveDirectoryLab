Veeam Agent requires access to backup servers. This GPO will push admin rights to ADLAB\Backup-Server-Admins Security Group. <br>
This GPO works in conjunction with 'Set up Backup server (BACKUP01).md and Configure GPO: Deny Logon.md
'<br> <br>

Create the GPO and link to OU.
```powershell
New-GPO `
    -Name "Member Servers - Backup Access"

New-GPLink `
    -Name "Member Servers - Backup Access" `
    -Target "OU=Servers,DC=adlab,DC=test" `
```

Configure GPO to grant admin access to ADLAB\Backup-Server-Admins
```text
Group Policy Management -> Member Servers - Backup Access -> right click -> Edit
Computer Configuration -> Preferences -> Control Panel Settings -> Local Users and Groups
Right click -> New -> Local Group
    Action: Update
    Group name: Administrators (built-in)
    Members -> Add...
        Name: ADLAB\Backup-Server-Admins
        Action: Add to this group
    OK -> Apply -> OK
```
