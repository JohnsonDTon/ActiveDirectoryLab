Create a test user. Run on DC01
```powershell
New-ADUser `
    -Name "Test Restore Two" `
    -SamAccountName "test.restore2" `
    -Path "CN=Users,DC=adlab,DC=test"
```

Run the DC01 job on Veeam in BACKUP01
```text
Home -> Jobs -> Lab Servers - DCs -> right click -> Start
```

Remove the test user. Run on DC01
```powershell
Remove-ADUser `
    -Identity "test.restore2" `
    -Confirm:$false
```

Restore test user via Veeam.
```text
Home (bottom left) -> Restore -> Agent... -> Application items restore ->
Microsoft Active Directory -> Choose DC012.adlab.test -> Next -> Pick the backup ->
Restore reason: "Test"
    Browse to CN=Users -> find Test Restore Two -> right click -> Restore
```

Verify. Run on DC01
```powershell
Get-ADUser -Identity "test.restore2"
```
