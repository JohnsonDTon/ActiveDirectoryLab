We first need to make an isolated switch to put the copy of the server to. The restored copy has the same name, IP, AD computer name as the original, and may break the real server's trust with the domain. <br>
Put it on a private switch with no connection to anything first. <br> <br>

Create Isolated switch. Run on Hyper-V Host
```powershell
New-VMSwitch `
    -Name "Restore-Test" `
    -SwitchType Private
```

Export the disk. Do on Veeam
```text
Home -> Restore -> Agent...
    Disk restore -> Export disks (VHDX)
    Select the WEC01 backup (Lab Servers - Members) -> latest restore point
    Export all volumes/disks
    Destination: a folder on BACKUP01 or a share, for example E:\Restore
    Format: VHDX
    Finish
```

```text
Copy the resulting VDHX to the Hyper-V host (for example E:\ActiveDirectoryLab\WEC01-Restore\)
```

Create a VM that uses this VDHX, attached to isolated switch only
```powershell
New-VM `
    -Name "WEC01-RestoreTest" `
    -Generation 2 `
    -MemoryStartupBytes 4GB `
    -VHDPath "E:\ActiveDirectoryLab\WEC01-Restore\WEC01.vhdx" `
    -SwitchName "Restore-Test"
```
```powershell
Start-VM `
    -Name "WEC01-RestoreTest"
```

Check if the service and subscription of that server is still active. For my test, I'm restoring back up to WEC01
```powershell
Get-Service Wecsvc
wecutil es
```

If it boots and the data is there, the proof is done. <br>
Clean up
```powershell
Stop-VM `
    -Name "WEC01-RestoreTest" `
    -TurnOff
Remove-VM `
    -Name "WEC01-RestoreTest" `
    -Force
```
