This GPO will be configuration/policy that governs BitLocker how it should act across your environment. <br>
Bitlocker helps encrypt your data in your hard-drive. <br>
This helps data protection in case your laptop/PC gets stolen. <br>
The stealer would need bitlocker recovery key in order to access the data <br> <br>

Create GPO and link to OU. Run on DC
```powershell
New-GPO -Name "Workstations - BitLocker"

New-GPLink `
    -Name "Workstations - BitLocker" `
    -Target "OU=Workstations,DC=adlab,DC=test"
```

Enable OS Recovery
```powershell
Set-GPRegistryValue `
    -Name "Workstations - BitLocker" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\FVE" `
    -ValueName "OSRecovery" `
    -Type DWord `
    -Value 1
```

Configure to require recovery password for BitLocker-protected operating system drives
```powershell
Set-GPRegistryValue `
    -Name "Workstations - BitLocker" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\FVE" `
    -ValueName "OSRecoveryPassword" `
    -Type DWord `
    -Value 1
```

Configure to require recovery key for BitLocker-protected operating system drives
```powershell
Set-GPRegistryValue `
    -Name "Workstations - BitLocker" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\FVE" `
    -ValueName "OSRecoveryKey" `
    -Type DWord `
    -Value 1
```

Configure the AD DS Backup <br>
This stores the recovery password and key-package in the on-prem AD.
```powershell
Set-GPRegistryValue `
    -Name "Workstations - BitLocker" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\FVE" `
    -ValueName "OSActiveDirectoryBackup" `
    -Type DWord `
    -Value 1
```
```powershell
Set-GPRegistryValue `
    -Name "Workstations - BitLocker" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\FVE" `
    -ValueName "OSActiveDirectoryInfoToStore" `
    -Type DWord `
    -Value 1
```

Require AD Backup before Bitlocker encryption <br>
Wouldn't want devices encrypted without having the key, right?
```powershell
Set-GPRegistryValue `
    -Name "Workstations - BitLocker" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\FVE" `
    -ValueName "OSRequireActiveDirectoryBackup" `
    -Type DWord `
    -Value 1
```

Use advanced startup. This means bootup requires more authentication, like TPM.
```powershell
Set-GPRegistryValue `
    -Name "Workstations - BitLocker" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\FVE" `
    -ValueName "UseAdvancedStartup" `
    -Type DWord `
    -Value 1
```


Check if CLIENT Machine is Bitlocker-enabled
```powershell
(Get-BitLockerVolume -MountPoint "C:").KeyProtector |
    Select-Object KeyProtectorType, KeyProtectorId
```

If not bitlocker enabled, Enable Bitlocker with XTS-AES 128 encryption. Run this on CLIENT machines.
```powershell
Enable-BitLocker `
    -MountPoint "C:" `
    -EncryptionMethod XtsAes128 `
    -UsedSpaceOnly `
    -TpmProtector
```
