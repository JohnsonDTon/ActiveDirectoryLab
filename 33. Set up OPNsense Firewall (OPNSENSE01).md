Using OPNsense version 26.7 <br> <br>

Download OPNsense ISO. Use options below when downloading
```text
https://opnsense.org/download/
System architecture: amd64
Image type:          dvd
Mirror Location:     any US mirror (or the default OPNsense one)

Extract the file to obtain the ISO
```

Variables for names I'll use. Run on Hyper-V Host
```powershell
$SwitchName = "AD-Lab-Internal"
$VMName = "OPNSENSE01"
$VHDPath = "E:\ActiveDirectoryLab\OPNSENSE01\OPNSENSE01.vhdx"
$ISOPath = "E:\ISO\OPNsense-26.7-dvd-amd64.iso"
```

Create VM.
```powershell
New-VM `
    -Name $VMName `
    -Generation 1 `
    -NewVHDPath $VHDPath `
    -NewVHDSizeBytes 20GB `
    -SwitchName "Default Switch"
```

Set Number of Processor for the VM.
```powershell
Set-VMProcessor -VMName $VMName -Count 2
```

Set RAM for the VM.
```powershell
Set-VMMemory `
    -VMName $VMName `
    -DynamicMemoryEnabled $false `
    -StartupBytes 4GB `
```

Add second NIC to VM
```powershell
Add-VMNetworkAdapter -VMName "OPNSENSE01" -SwitchName $SwitchName
```

Turn Checkpoints (snapshots) off. <br>
This is optional, prefer to use planned backups on my own so keeping it disabled for this lab.
```powershell
Set-VM -Name $VMName -CheckpointType Disabled
```
<br>

Check Checkpoint settings
```powershell
Get-VM -Name $VMName | Select-Object Name, CheckpointType
```
<br>

Check if you have VM DVD Drive.<br>
Need this to install OS on VM.
```powershell
Get-VMDvdDrive -VMName $VMName
```
<br>

Add VM DVD Drive, do if you don't have it.
```powershell
Add-VMDvdDrive -VMName $VMName
```
<br>

Mount the ISO file to the VM. <br>
```powershell
Set-VMDvdDrive `
    -VMName $VMName `
    -Path $ISOPath
```
<br>

Start up the VM.
```powershell
Start-VM -Name $VMName
```
<br>

Open the VM in a different window. Do this after you started it up.
```powershell
vmconnect.exe localhost $VMName
```
<br>

Run the Installer <br>
Default OPNsense credentials are (as of 10/11/2026)
```text
Login:    installer
Password: opnsense
```
```text
Keymap:       Continue with default keymap
Install type: Install (ZFS)
Select Virtual Device Type: stripe Stripe - No Redundancy
Disk:         select the 20 GB disk
Root password: set a strong one and record it in your password manager
Complete Install -> Reboot
```


Un-mount the ISO file from the VM. <br>
Take this off or it'll keep booting to ISO
```powershell
Set-VMDvdDrive -VMName $VMName -Path $null
```
<br>

Check if VM has any ISOs mounted.
```powershell
Get-VMDvdDrive -VMName $VMName
```
<br>

Confirm NIC order. Need this to pick in the installer which is WAN and which is LAN. Run on Hyper-V Host
```powershell
Get-VMNetworkAdapter -VMName "OPNSENSE01" | Select-Object Name, SwitchName, MacAddress
```

Start up OPNsense again without ISO mounted <br> <br>
