I will be using AGDLP approach when designing this lab. <br>
This assumes you made 4 file shares of IT, HR, Finance, and Public. <br> <br>

We want to use Security Groups because not all people in IT OU need access to the files of IT Share Drive <br>
We only give it to those who needs it. Least privilege Principle. <br> <br>

Create OUs to hold the Security Groups
```powershell
$DomainDN = "DC=adlab,DC=test"

New-ADOrganizationalUnit `
    -Name "Security Groups" `
    -Path $DomainDN

New-ADOrganizationalUnit `
    -Name "Global" `
    -Path "OU=Security Groups,$DomainDN"

New-ADOrganizationalUnit `
    -Name "Domain Local" `
    -Path "OU=Security Groups,$DomainDN"
```

Create Global Security Groups
``` powershell
$GlobalOU = "OU=Global,OU=Security Groups,DC=adlab,DC=test"

New-ADGroup `
    -Name "GG-All-Employees" `
    -SamAccountName "GG-All-Employees" `
    -GroupScope Global `
    -GroupCategory Security `
    -Path $GlobalOU

New-ADGroup `
    -Name "GG-IT-Users" `
    -SamAccountName "GG-IT-Users" `
    -GroupScope Global `
    -GroupCategory Security `
    -Path $GlobalOU

New-ADGroup `
    -Name "GG-HR-Users" `
    -SamAccountName "GG-HR-Users" `
    -GroupScope Global `
    -GroupCategory Security `
    -Path $GlobalOU

New-ADGroup `
    -Name "GG-Finance-Users" `
    -SamAccountName "GG-Finance-Users" `
    -GroupScope Global `
    -GroupCategory Security `
    -Path $GlobalOU
```

Verify
```powershell
Get-ADGroup `
    -SearchBase $GlobalOU `
    -Filter * |
    Select-Object Name, GroupScope, GroupCategory
```

Declare Variable for Domain Local Security Group
```powershell
$DomainLocalOU = "OU=Domain Local,OU=Security Groups,DC=adlab,DC=test"
```

Create Domain Local Security Group for IT
```powershell
New-ADGroup `
    -Name "DL-FILE01-IT-Read" `
    -SamAccountName "DL-FILE01-IT-Read" `
    -GroupScope DomainLocal `
    -GroupCategory Security `
    -Path $DomainLocalOU

New-ADGroup `
    -Name "DL-FILE01-IT-Modify" `
    -SamAccountName "DL-FILE01-IT-Modify" `
```
