Create GPO and link to OU.
```powershell
New-GPO `
    -Name "Servers - Windows Update" `
    -Comment "Servers use WSUS01, install on a schedule, no restart with signed-in users"

New-GPLink `
    -Name "Servers - Windows Update" `
    -Target "OU=Servers,DC=adlab,DC=test" `
    -LinkEnabled Yes
```

Point servers to use WSUS and the 'Servers' group for Windows Update
```powershell
Set-GPRegistryValue `
    -Name "Servers - Windows Update" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate" `
    -ValueName "WUServer" `
    -Type String `
    -Value "http://WSUS01.adlab.test:8530"
```
```powershell
Set-GPRegistryValue `
    -Name "Servers - Windows Update" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate" `
    -ValueName "WUStatusServer" `
    -Type String `
    -Value "http://WSUS01.adlab.test:8530"
```
```powershell
Set-GPRegistryValue `
    -Name "Servers - Windows Update" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate\AU" `
    -ValueName "UseWUServer" `

```

Set to download automatically and do scheduled installs
```powershell
Set-GPRegistryValue `
    -Name "Servers - Windows Update" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate\AU" `
    -ValueName "AUOptions" `
    -Type DWord `
    -Value 4
```

Set scheduled install days onto Saturday
```powershell
Set-GPRegistryValue `
    -Name "Servers - Windows Update" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate\AU" `
    -ValueName "ScheduledInstallDay" `
    -Type DWord `
    -Value 7
```

Set scheduled time to 3:00 AM
```powershell
Set-GPRegistryValue `
    -Name "Servers - Windows Update" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate\AU" `
    -ValueName "ScheduledInstallTime" `
    -Type DWord `
    -Value 3
```

Disable logged in users needing to reboot
```powershell
Set-GPRegistryValue `
    -Name "Servers - Windows Update" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate\AU" `
    -ValueName "NoAutoRebootWithLoggedOnUsers" `
    -Type DWord `
    -Value 1
```

Verify. Should show http://WSUS01.adlab.test:8530 atnd Servers. Run on WEC01
```powershell
gpupdate /force
```
```powershell
Get-ItemProperty `
    -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate" |
    Select-Object WUServer, WUStatusServer, TargetGroup
```

Make it check in
```powershell
UsoClient StartScan
```
Check for http://WSUS01.adlab.test:8530. It means its talking to the WSUS
```powershell
Get-WindowsUpdateLog
```
The server should appear in WSUS console after a few minutes
```text
Under Computers -> All Computers -> Servers
```

You can now approve updates on WSUS. But since my WEC01 was running automatically getting updates directly from Microsoft, I was already up-to-date.
