Create GPO and link to OU.
```powershell
New-GPO `
    -Name "Servers - Advanced Auditing" `
    -Comment "Advanced audit policy for member servers"

New-GPLink `
    -Name "Servers - Advanced Auditing" `
    -Target "OU=Servers,DC=adlab,DC=test" `
    -LinkEnabled Yes
```

Disable the Legacy Audit Policy
```powershell
Set-GPRegistryValue `
    -Name "Servers - Advanced Auditing" `
    -Key "HKLM\SYSTEM\CurrentControlSet\Control\Lsa" `
    -ValueName "SCENoApplyLegacyAuditPolicy" `
    -Type DWord `
    -Value 1
```

Enable logging Processes event (4688)
```powershell
Set-GPRegistryValue `
    -Name "Servers - Advanced Auditing" `
    -Key "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System\Audit" `
    -ValueName "ProcessCreationIncludeCmdLine_Enabled" `
    -Type DWord `
    -Value 1
```

Configure Credential Validation Logging <br>
Logs: a server checking a username and password through NTLM <br>
Events: 4776 <br>
Why: shows password guessing and NTLM use against the server
```text
Group Policy Management -> Servers - Advanced Auditing -> Edit...
Computer Configuration -> Policies -> Windows Settings -> Security Settings -> Advanced Audit Policy Configuration -> Audit Policies

Double click Account Logon

Audit Credential Validation: Check 'Configure the following audit events:', Success, Failure
Apply -> Ok
```
