Create GPO and link to OU.
```powershell
New-GPO `
    -Name "Servers - Advanced Auditing" `
    -Comment "Advanced audit policy for member servers"

New-GPLink `
    -Name "Servers - Advanced Auditing" `
    -Target "OU=Servers,DC=adlab,DC=test" `
    -LinkEnabled Yes
```

Disable the Legacy Audit Policy
```powershell
Set-GPRegistryValue `
    -Name "Servers - Advanced Auditing" `
    -Key "HKLM\SYSTEM\CurrentControlSet\Control\Lsa" `
    -ValueName "SCENoApplyLegacyAuditPolicy" `
    -Type DWord `
    -Value 1
```

Enable logging Processes event to include command line logging (4688)
```powershell
Set-GPRegistryValue `
    -Name "Servers - Advanced Auditing" `
    -Key "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System\Audit" `
    -ValueName "ProcessCreationIncludeCmdLine_Enabled" `
    -Type DWord `
    -Value 1
```
