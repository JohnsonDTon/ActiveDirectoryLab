This assumes your Network Share is built like this on your File Server (FILE01).
```text
├── C:\                  Windows Server OS
├── D:\                  DVD Drive
└── E:\                  FileServerData
    └── Shares
        ├── IT
        ├── HR
        ├── Finance
        └── Public
```
Also assume you have this security group
```text
ADLAB.TEST
│
└── Security Groups
    │
    ├── Global
    │   ├── GG-All-Employees
    │   ├── GG-IT-Users
    │   ├── GG-HR-Users
    │   └── GG-Finance-Users
    │
    └── Domain Local
        ├── DL-FILE01-IT-Read
        ├── DL-FILE01-IT-Modify
        ├── DL-FILE01-IT-Full
        ├── DL-FILE01-HR-Read
        ├── DL-FILE01-HR-Modify
        ├── DL-FILE01-HR-Full
        ├── DL-FILE01-Finance-Read
        ├── DL-FILE01-Finance-Modify
        ├── DL-FILE01-Finance-Full
        ├── DL-FILE01-Public-Read
        ├── DL-FILE01-Public-Modify
        └── DL-FILE01-Public-Full
```
<br><br>


```powershell
Get-Acl "E:\Shares\IT" |
    Select-Object -ExpandProperty Access

Get-Acl "E:\Shares\HR" |
    Select-Object -ExpandProperty Access

Get-Acl "E:\Shares\Finance" |
    Select-Object -ExpandProperty Access

Get-Acl "E:\Shares\Public" |
    Select-Object -ExpandProperty Access
```
