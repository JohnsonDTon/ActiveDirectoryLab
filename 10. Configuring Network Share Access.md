This assumes your Network Share is built like this
```text
├── C:\                  Windows Server OS
├── D:\                  DVD Drive
└── E:\                  FileServerData
    └── Shares
        ├── IT
        ├── HR
        ├── Finance
        └── Public
```


```powershell
Get-Acl "E:\Shares\IT" |
    Select-Object -ExpandProperty Access

Get-Acl "E:\Shares\HR" |
    Select-Object -ExpandProperty Access

Get-Acl "E:\Shares\Finance" |
    Select-Object -ExpandProperty Access

Get-Acl "E:\Shares\Public" |
    Select-Object -ExpandProperty Access
```
