We are going to create user accounts on Active Directory.
```text
| User  | Full Name               | Department / OU |
| ----- | ----------------------- | --------------- |
| Alice | **Alice Marie Johnson** | IT              |
| Bob   | **Bob Thomas Smith**    | HR              |
| Carol | **Carol Davis**         | Finance         |
| David | **David James Wilson**  | Standard Users  |
```
Run on DC <br> <br>

Create user accounts. It will ask to create a temp password for each user.
```powershell
New-ADUser `
    -Name "Alice Marie Johnson" `
    -GivenName "Alice" `
    -Initials "M" `
    -Surname "Johnson" `
    -DisplayName "Alice Marie Johnson" `
    -SamAccountName "alice.johnson" `
    -UserPrincipalName "alice.johnson@adlab.test" `
    -Path "OU=IT,OU=User Accounts,DC=adlab,DC=test" `
    -AccountPassword (Read-Host -AsSecureString "Password for Alice") `
    -Enabled $true

New-ADUser `
    -Name "Bob Thomas Smith" `
    -GivenName "Bob" `
    -Initials "T" `
    -Surname "Smith" `
    -DisplayName "Bob Thomas Smith" `
    -SamAccountName "bob.smith" `
    -UserPrincipalName "bob.smith@adlab.test" `
    -Path "OU=HR,OU=User Accounts,DC=adlab,DC=test" `
    -AccountPassword (Read-Host -AsSecureString "Password for Bob") `
    -Enabled $true

New-ADUser `
    -Name "Carol Davis" `
    -GivenName "Carol" `
    -Surname "Davis" `
    -DisplayName "Carol Davis" `
    -SamAccountName "carol.davis" `
    -UserPrincipalName "carol.davis@adlab.test" `
    -Path "OU=Finance,OU=User Accounts,DC=adlab,DC=test" `
    -AccountPassword (Read-Host -AsSecureString "Password for Carol") `
    -Enabled $true

New-ADUser `
    -Name "David James Wilson" `
    -GivenName "David" `
    -Initials "J" `
    -Surname "Wilson" `
    -DisplayName "David James Wilson" `
    -SamAccountName "david.wilson" `
    -UserPrincipalName "david.wilson@adlab.test" `
    -Path "OU=Standard Users,OU=User Accounts,DC=adlab,DC=test" `
    -AccountPassword (Read-Host -AsSecureString "Password for David") `
    -Enabled $true
```

Verify
```powershell
Get-ADUser -Filter * `
    -SearchBase "OU=User Accounts,DC=adlab,DC=test" `
    -Properties GivenName,Initials,Surname,DisplayName |
    Select-Object Name,GivenName,Initials,Surname,DisplayName,SamAccountName,UserPrincipalName
```

Add user accounts to appropriate Security Groups
```powershell
Add-ADGroupMember `
    -Identity "GG-IT-Users" `
    -Members "alice.johnson"

Add-ADGroupMember `
    -Identity "GG-HR-Users" `
    -Members "bob.smith"

Add-ADGroupMember `
    -Identity "GG-Finance-Users" `
    -Members "carol.davis"

Add-ADGroupMember `
    -Identity "GG-All-Employees" `
    -Members "alice.johnson","bob.smith","carol.davis", "david.wilson"
```

Verify
```powershell
Get-ADGroupMember "GG-IT-Users"
Get-ADGroupMember "GG-HR-Users"
Get-ADGroupMember "GG-Finance-Users"
Get-ADGroupMember "GG-All-Employees"
```
