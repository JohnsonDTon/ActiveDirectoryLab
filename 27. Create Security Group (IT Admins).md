Create Global Security Group
``` powershell
 New-ADGroup `
    -Name "GG-IT-Admins" `
    -GroupScope Global `
    -GroupCategory Security `
    -Path "OU=Global,OU=Security Groups,DC=adlab,DC=test"
```

Add user to security group
```powershell
Add-ADGroupMember `
    -Identity "GG-IT-Admins" `
    -Members "3alice.johnson"
```
