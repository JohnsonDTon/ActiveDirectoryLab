Run this on a fresh Windows Server VM that you'd making it to be your DC. <br>
Reference: https://github.com/JohnsonDTon/ActiveDirectoryLab/blob/main/3.%20Create%20VM.md <br>
Make sure that fresh VM is renamed, and IP/DNS configured if it haven't. <br>
Reference: https://github.com/JohnsonDTon/ActiveDirectoryLab/blob/main/4.%20Configure%20IP.md <br>

Install Active Directory Domain Services
```powershell
Install-WindowsFeature AD-Domain-Services -IncludeManagementTools
```
<br>

Create AD Forest and name your domain. <br>
This step promotes this server to be your first domain controller and creates your AD environment.
```powershell
Install-ADDSForest `
    -DomainName "adlab.test" `
    -DomainNetbiosName "ADLAB"
```
<br>

Verify
```powershell
Get-ADDomain
Get-ADForest
Get-ADDomainController
Resolve-DnsName adlab.test
Resolve-DnsName DC01.adlab.test
```

Check if Domain Controller is healthy. If no output, that means no problem. <br>
If you get time server issue only, that is expected since you're not connected to internet.
```powershell
dcdiag /q
```
