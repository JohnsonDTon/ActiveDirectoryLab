Access-Based Enumeration (ABE) hides files/folders if user does not have access to it. <br>

Check current FolderEnumerationMode settings. Most likely unrestricted since we just created it.
```powershell
Get-SmbShare |
    Where-Object Name -in "IT","HR","Finance","Public" |
    Select-Object Name, FolderEnumerationMode
```

Enable ABE
```powershell
$Shares = @(
    "IT",
    "HR",
    "Finance",
    "Public"
)

foreach ($Share in $Shares) {
    Set-SmbShare `
        -Name $Share `
        -FolderEnumerationMode AccessBased `
        -Force
}
```

Verify. You should see AccessBased now.
```powershell
Get-SmbShare |
    Where-Object Name -in "IT","HR","Finance","Public" |
    Select-Object Name, FolderEnumerationMode
```
