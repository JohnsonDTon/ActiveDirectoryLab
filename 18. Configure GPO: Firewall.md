For good practice, we want to deny-by-default for inbound actions. We only accept inbound if we specifically allow it. <br>
We want to allow outbound because thats us sending out data. From there, we can block specifics if theyre security standards<br> <br>

Firewall has 3 network profiles (DomainProfile, PrivateProfile, PubicProfile) <br>
So we'll adjust policies for all 3 profiles <br>

Create GPO and link it to workstation OU.
```powershell
New-GPO -Name "Workstations - Firewall"

New-GPLink `
    -Name "Workstations - Firewall" `
    -Target "OU=Workstations,DC=adlab,DC=test"
```

Using GPO to enable Firewall, Block inbound action by default, and Allow outbound by default
```powerhsell
$PolicyStore = "adlab.test\Workstations - Firewall"

Set-NetFirewallProfile `
    -Name Domain,Private,Public `
    -PolicyStore $PolicyStore `
    -Enabled True `
    -DefaultInboundAction Block `
    -DefaultOutboundAction Allow
```
