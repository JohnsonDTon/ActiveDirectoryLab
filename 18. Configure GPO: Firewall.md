For good practice, we want to deny-by-default for inbound actions. We only accept inbound if we specifically allow it. <br>
We want to allow outbound because thats us sending out data. From there, we can block specifics if theyre security standards<br>
There's honestly alot of firewall rules to do that are good practices, will come revisit this one to add more in the future. <br> <br>

Firewall has 3 network profiles (DomainProfile, PrivateProfile, PubicProfile) <br>
So we'll adjust policies for all 3 profiles <br>

Create GPO and link it to workstation OU.
```powershell
New-GPO -Name "Workstations - Firewall"

New-GPLink `
    -Name "Workstations - Firewall" `
    -Target "OU=Workstations,DC=adlab,DC=test"
```

Use GPO to enable Firewall, Block inbound action by default, and Allow outbound by default
```powerhsell
$PolicyStore = "adlab.test\Workstations - Firewall"

Set-NetFirewallProfile `
    -Name Domain,Private,Public `
    -PolicyStore $PolicyStore `
    -Enabled True `
    -DefaultInboundAction Block `
    -DefaultOutboundAction Allow
```

Use GPO to log firewall allows and blocks <br>
Default location: C:\Windows\System32\LogFiles\Firewall\pfirewall.log <br>
```powershell
$PolicyStore = "adlab.test\Workstations - Firewall"

Set-NetFirewallProfile `
    -Name Domain,Private,Public `
    -PolicyStore $PolicyStore `
    -LogBlocked True `
    -LogAllowed True `
    -LogMaxSizeKilobytes 20480
```

Can read logs using the following:
```powershell
Get-Content "$env:SystemRoot\System32\LogFiles\Firewall\pfirewall.log" |
    Select-Object -Last 30
```
```powershell
Get-Content "$env:SystemRoot\System32\LogFiles\Firewall\pfirewall.log" -Wait
```

Use GPO to disable local firewall rules
```powershell
Set-NetFirewallProfile `
    -Name Domain,Private,Public `
    -PolicyStore $PolicyStore `
    -AllowLocalFirewallRules False
```

Verify the complete baseline
```powershell
Get-NetFirewallProfile `
    -PolicyStore $PolicyStore |
    Select-Object Name,
                  Enabled,
                  DefaultInboundAction,
                  DefaultOutboundAction,
                  AllowLocalFirewallRules,
                  LogBlocked,
                  LogAllowed,
                  LogMaxSizeKilobytes
```
