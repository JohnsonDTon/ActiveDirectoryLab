We want to make a Bitlocker GPO to backup Bitlocker recovery keys to AD. <br> 
Bitlocker recovery key is used when TPM boot fails and you need Bitlocker recovery key to work with your encrypted data <br>
It is good to have it accessible from your AD in case you run into TPM issues <br> <br>

Create GPO and link to OU.
```powershell
New-GPO -Name "Workstations - BitLocker"

New-GPLink `
    -Name "Workstations - BitLocker" `
    -Target "OU=Workstations,DC=adlab,DC=test"
```

Configure recovery key backup to AD
```text
Right click 'Workstations - BitLocker' -> Edit...
Computer Configuration
└── Policies
    └── Administrative Templates
        └── Windows Components
            └── BitLocker Drive Encryption
                └── Operating System Drives

Double-click 'Choose how BitLocker-protected operating system drives can be recovered'
Select Enabled.

Checkbox: Allow data recovery agent (this is checked default)
Configure user storage of BitLocker recovery information:
    Allow 48-digit recovery password (this is checked default)
    Allow 256-bit recovery key (this is checked default)
Checkbox: Omit recovery options from the BitLocker setup wizard   (leave unchecked)
Checkbox: Save BitLocker recovery information to AD DS for operating system drives (this is checked default)
    Configure storage of BitLocker recovery information to AD DS:
    Store recovery passwords and key packages (this is default)
Check the Checkbox 'Do not enable BitLocker until recovery information is stored in AD DS for operating system drives'

Apply
OK
```

On each workstation, make sure TPM is on (it's on BIOS settings in physical machine)
```powershell
Get-Tpm
```

Check status of Bitlocker on client (Look at KeyProtector and Protection Status)
```powershell
Get-BitLockerVolume
```

Enable Bitlocker on each workstation (unfortunately this has to be done manually if it wasn't done when provisioned)
```powershell
gpupdate /force
```
```powershell
Add-BitLockerKeyProtector -MountPoint "C:" -TpmProtector
Add-BitLockerKeyProtector -MountPoint "C:" -RecoveryPasswordProtector
Resume-BitLocker -MountPoint "C:"
```

Verify on workstation
```powershell
Get-BitLockerVolume
```
```powershell
manage-bde -protectors -get C:
```

Verify AD has the Bitlocker keys.Run on DC
```powershell
Get-ADObject `
    -Filter 'objectClass -eq "msFVE-RecoveryInformation"' `
    -SearchBase "OU=Workstations,DC=adlab,DC=test" |
    Select-Object DistinguishedName
```
