Create GPO and link to OU
```powershell
New-GPO -Name "Workstations - Windows Update"

New-GPLink `
    -Name "Workstations - Windows Update" `
    -Target "OU=Workstations,DC=adlab,DC=test"
```

Turn on Automatic updates
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Windows Update" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate\AU" `
    -ValueName "NoAutoUpdate" -Type DWord -Value 0
```

Automatically download the updates
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Windows Update" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate\AU" `
    -ValueName "AUOptions" -Type DWord -Value 4
```

Set the installation day. 0 is everyday
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Windows Update" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate\AU" `
    -ValueName "ScheduledInstallDay" -Type DWord -Value 0
```

Set the installation time, 3 is 3 am.
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Windows Update" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate\AU" `
    -ValueName "ScheduledInstallTime" -Type DWord -Value 3
```

Enable active hours (These are hours where windows update wont automatically restart)
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Windows Update" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate" `
    -ValueName "SetActiveHours" -Type DWord -Value 1
```

Active hour start at 8am
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Windows Update" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate" `
    -ValueName "ActiveHoursStart" -Type DWord -Value 8
```

Active hour stop at 6pm
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Windows Update" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate" `
    -ValueName "ActiveHoursEnd" -Type DWord -Value 18
```


Enable the Windows 11 feature Update option <br>
Microsoft does yearly big updates. It can break apps, drivers, or other GPOs. Best to test big updates on a few machines first before rolling it all out
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Windows Update" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate" `
    -ValueName "TargetReleaseVersion" -Type DWord -Value 1
```

For Windows 11 feature Update option, Set to Windows 11
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Windows Update" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate" `
    -ValueName "ProductVersion" -Type String -Value "Windows 11"
```

Pin it to current version. Mine is currently 25H2. Check this by running on client: (Get-ItemProperty "HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion").DisplayVersion
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Windows Update" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate" `
    -ValueName "TargetReleaseVersionInfo" -Type String -Value "25H2"
```

Verify via html file

```powershell
Get-GPOReport `

    -Path C:\wu-report.html
```
