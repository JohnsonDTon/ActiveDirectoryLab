We want Powershell Logging for auditing purposes. <br>
You may know bob log into WIN11-02, but with this, you would know what powershell commands were executed, what scripts were ran, and what modules were used <br>
These will be logged onto Event viewer of your client workstations. Applications and Services Logs → Microsoft → Windows → PowerShell → Operational. Event 4104 <br>
Note that powershell logging can contain sensitive information. So we'd need to control access to these logs too once implemented <br> <br>

Create and link the GPO. Run on DC.
```powershell
New-GPO -Name "Workstations - PowerShell Logging"

New-GPLink `
    -Name "Workstations - PowerShell Logging" `
    -Target "OU=Workstations,DC=adlab,DC=test"
```

Enable Script Block Logging <br>
It records PowerShell commands, script blocks, functions, and scripts processed by the engine.
```powershell
Set-GPRegistryValue `
    -Name "Workstations - PowerShell Logging" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\PowerShell\ScriptBlockLogging" `
    -ValueName "EnableScriptBlockLogging" `
    -Type DWord `
    -Value 1
```
Turn Script Block Invocation Logging off <br>
PowerShell starts recording invocation start/stop information for script blocks. <br>
This is too much noise and hard to read the logs when enabled
```powershell
Set-GPRegistryValue `
    -Name "Workstations - PowerShell Logging" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\PowerShell\ScriptBlockLogging" `
    -ValueName "EnableScriptBlockInvocationLogging" `
    -Type DWord `
    -Value 0
```

Enable Module Logging
```powershell
Set-GPRegistryValue `
    -Name "Workstations - PowerShell Logging" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\PowerShell\ModuleLogging" `
    -ValueName "EnableModuleLogging" `
    -Type DWord `
    -Value 1
```

Log all modules via "*" <br>
This is appropriate for a small lab, but in enterprise you'd want to change this base on whats important for your environment <br>
Otherwise it will be bunch of unneccessary data
```powershell
Set-GPRegistryValue `
    -Name "Workstations - PowerShell Logging" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\PowerShell\ModuleLogging\ModuleNames" `
    -ValueName "*" `
    -Type String `
    -Value "*"
```

Enable PowerShell Transcription
```powershell
Set-GPRegistryValue `
    -Name "Workstations - PowerShell Logging" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\PowerShell\Transcription" `
    -ValueName "EnableTranscripting" `
    -Type DWord `
    -Value 1
```

Enable Invocation Header. This helps readability
```powershell
Set-GPRegistryValue `
    -Name "Workstations - PowerShell Logging" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\PowerShell\Transcription" `
    -ValueName "EnableInvocationHeader" `
    -Type DWord `
    -Value 1
```

Look through the commands you ran via Powershell Logging
```powershell
Get-WinEvent `
    -LogName "Microsoft-Windows-PowerShell/Operational" `
    -FilterXPath "*[System[(EventID=4104)]]" `
    -MaxEvents 20 |
    ForEach-Object {
        [PSCustomObject]@{
            TimeCreated = $_.TimeCreated
            Id          = $_.Id
            Message     = $_.Message
        }
    } |
    Format-List
```
