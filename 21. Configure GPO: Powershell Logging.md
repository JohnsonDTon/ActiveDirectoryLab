We want Powershell Logging for auditing purposes. <br>
You may know bob log into WIN11-02, but with this, you would know what powershell commands were executed, what scripts were ran, and what modules were used <br> <br>

Create and link the GPO. Run on DC.
```powershell
New-GPO -Name "Workstations - PowerShell Logging"

New-GPLink `
    -Name "Workstations - PowerShell Logging" `
    -Target "OU=Workstations,DC=adlab,DC=test"
```

Enable Script Block Logging <br>
It records PowerShell commands, script blocks, functions, and scripts processed by the engine.
```powershell
Set-GPRegistryValue `
    -Name "Workstations - PowerShell Logging" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\PowerShell\ScriptBlockLogging" `
    -ValueName "EnableScriptBlockLogging" `
    -Type DWord `
    -Value 1
```
Turn Script Block Invocation Logging off <br>
PowerShell starts recording invocation start/stop information for script blocks. <br>
This is too much noise and hard to read the logs when enabled
```powershell
Set-GPRegistryValue `
    -Name "Workstations - PowerShell Logging" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\PowerShell\ScriptBlockLogging" `
    -ValueName "EnableScriptBlockInvocationLogging" `
    -Type DWord `
    -Value 0
```
