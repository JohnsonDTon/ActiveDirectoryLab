This GPO works in conjunction with 'Workstations - Windows Logging' GPO. That GPO decides how much room Windows gives those records and what happens when the logs fill up.<br>
This one decides what Windows record (successfuly log in, failed log in, process starts, a user/group change, etc) <br> <br>

Create GPO and link to OU. Run on DC
```powershell
New-GPO -Name "Workstations - Advanced Auditing"

New-GPLink `
    -Name "Workstations - Advanced Auditing" `
    -Target "OU=Workstations,DC=adlab,DC=test"
```

To go to configuration:
```text
Go to a DC, Group Policy Management
Under Workstations OU, right click 'Workstations - Advanced Auditing'
Edit...

Computer Configuration
└── Policies
    └── Windows Settings
        └── Security Settings
            └── Advanced Audit Policy Configuration
                └── Audit Policies
```

Configure account logon auditing: Track Credential validation <br>
Whenever a user account logs in, logs both success + failure validation (like incorrect pw)
```text
Account Logon → Audit Credential Validation

Select:

☑ Configure the following audit events
☑ Success
☑ Failure
```
