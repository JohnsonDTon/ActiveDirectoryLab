Run this on a fresh (and named) Windows Server VM that you'd making it to be your backup DC. <br>
Reference: https://github.com/JohnsonDTon/ActiveDirectoryLab/blob/main/3.%20Create%20VM.md <br>
Make sure IP/DNS configured if it haven't. (DC02 uses DC01 as DNS, but this gets changed once the VM is a DC) <br>
Reference: https://github.com/JohnsonDTon/ActiveDirectoryLab/blob/main/4.%20Configure%20IP.md <br>
Make sure you already configured your first DC, as this one is your backup. <br>
Reference: https://github.com/JohnsonDTon/ActiveDirectoryLab/blob/main/5.%20Set%20Up%20Domain%20Controller%20(DC01).md <br>

Join this computer to your domain
```powershell
Add-Computer `
    -DomainName "adlab.test" `
    -Credential "ADLAB\Administrator" `
    -Restart
```
<br>

Install AD DS
```powershell
Install-WindowsFeature AD-Domain-Services -IncludeManagementTools
```
<br>

Promote DC02 to Domain Controller and Install DNS. You want DC02 to act as redundant DNS server too. <br>
It will ask SafeModeAdministratorPassword. This creates a emergency AD recovery password used for Directory Services Restore Mode (DSRM)
```powershell
Install-ADDSDomainController `
    -DomainName "adlab.test" `
    -InstallDns
```
<br>

Verify Replication. You should see '0/5' tests, which means it succeeded.
```powershell
repadmin /replsummary
```
<br>

Verify who DC02 is replicating with. You will see DC01.
```powershell
repadmin /showrepl
```
<br>

Verify DC health. If nothing pops up, its good.
```powershell
dcdiag /q
```
<br>

Reconfigure DNS Settings
```powershell
Set-DnsClientServerAddress `
    -InterfaceAlias "Ethernet" `
    -ServerAddresses "192.168.100.11"
```
<br>

Test Replication <br>
Do on DC01
```powershell
New-ADUser -Name "ReplicationTest"
```
Do on DC02
```powershell
Get-ADUser -Identity "ReplicationTest"
```
Do on any DC if success
```powershell
Remove-ADUser "ReplicationTest"
```
