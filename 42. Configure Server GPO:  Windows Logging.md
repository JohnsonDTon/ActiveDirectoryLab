Create GPO and link to OU
```powershell
New-GPO `
    -Name "Servers - Windows Logging" `
    -Comment "Event log sizes and retention for member servers"

New-GPLink `
    -Name "Servers - Windows Logging" `
    -Target "OU=Servers,DC=adlab,DC=test" `
    -LinkEnabled Yes
```

Set sizes for Security logs, System logs, and application logs
```powershell
Set-GPRegistryValue `
    -Name "Servers - Windows Logging" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\EventLog\Security" `
    -ValueName "MaxSize" `
    -Type DWord `
    -Value 262144
```
```powershell
Set-GPRegistryValue `
    -Name "Servers - Windows Logging" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\EventLog\System" `
    -ValueName "MaxSize" `
    -Type DWord `
    -Value 65536
```
```powershell
Set-GPRegistryValue `
    -Name "Servers - Windows Logging" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\EventLog\Application" `
    -ValueName "MaxSize" `
    -Type DWord `
    -Value 65536
```
