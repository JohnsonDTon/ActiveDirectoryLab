Create group policy
```powershell
New-GPO -Name "Workstations - Security Baseline"
```

Link to 'Workstations' OU
```powershell
New-GPLink `
    -Name "Workstations - Security Baseline" `
    -Target "OU=Workstations,DC=adlab,DC=test"
```

Verify.
```powershell
Get-GPInheritance `
    -Target "OU=Workstations,DC=adlab,DC=test"
```
```powershell
Get-GPO -Name "Workstations - Security Baseline" |
    Select-Object DisplayName, Id, GpoStatus
```

Turn on User Account Control (UAC) <br>
It's on by default for Win 11, but lets assure it via GPO.
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Security Baseline" `
    -Key "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" `
    -ValueName "EnableLUA" `
    -Type DWord `
    -Value 1
```

Verify on Windows Client.
```powershell
gpupdate /force

Get-ItemProperty `
    -Path "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" `
    -Name EnableLUA
```
