Create GPO and link to OU.
```powershell
New-GPO `
    -Name "Servers - PowerShell Logging" `
    -Comment "Script block and module logging for member servers"

New-GPLink `
    -Name "Servers - PowerShell Logging" `
    -Target "OU=Servers,DC=adlab,DC=test" `
    -LinkEnabled Yes
```

Enable Script Block Logging
```powershell
Set-GPRegistryValue `
    -Name "Servers - PowerShell Logging" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\PowerShell\ScriptBlockLogging" `
    -ValueName "EnableScriptBlockLogging" `
    -Type DWord `
    -Value 1
```

Enable Module Logging for all Modules
```powershell
Set-GPRegistryValue `
    -Name "Servers - PowerShell Logging" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\PowerShell\ModuleLogging" `
    -ValueName "EnableModuleLogging" `
    -Type DWord `
    -Value 1
```
```powershell
Set-GPRegistryValue `
    -Name "Servers - PowerShell Logging" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\PowerShell\ModuleLogging\ModuleNames" `
    -ValueName "*" `
    -Type String `
    -Value "*"
```
