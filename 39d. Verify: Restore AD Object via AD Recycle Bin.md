Create a test user on DC01. Run on DC01.
```powershell
New-ADUser `
    -Name "Test Restore" `
    -SamAccountName "test.restore" `
    -Path "CN=Users,DC=adlab,DC=test"
```

Remove the test user.
```powershell
Remove-ADUser `
    -Identity "test.restore" `
    -Confirm:$false
```

Recover from AD Recycle Bin
```powershell
Get-ADObject `
    -Filter 'SamAccountName -eq "test.restore"' `
    -IncludeDeletedObjects |
    Restore-ADObject
```

Verify
```powershell
Get-ADUser `
    -Identity "test.restore"
```
