Run on any DC below <br> <br>

Define variable
```powershell
$DomainDN = "DC=adlab,DC=test"
```

Create top-level OUs.
```powershell
New-ADOrganizationalUnit -Name "User Accounts" -Path "DC=adlab,DC=test"
New-ADOrganizationalUnit -Name "Workstations" -Path "DC=adlab,DC=test"
New-ADOrganizationalUnit -Name "Servers" -Path "DC=adlab,DC=test"
New-ADOrganizationalUnit -Name "Service Accounts" -Path "DC=adlab,DC=test"
```

Create User Account OUs.
```powershell
New-ADOrganizationalUnit -Name "IT" -Path "OU=User Accounts,$DomainDN"
New-ADOrganizationalUnit -Name "HR" -Path "OU=User Accounts,$DomainDN"
New-ADOrganizationalUnit -Name "Finance" -Path "OU=User Accounts,$DomainDN"
New-ADOrganizationalUnit -Name "Standard Users" -Path "OU=User Accounts,$DomainDN"
```

Create Workstations OUs.
```powershell
New-ADOrganizationalUnit -Name "IT" -Path "OU=Workstations,$DomainDN"
New-ADOrganizationalUnit -Name "HR" -Path "OU=Workstations,$DomainDN"
New-ADOrganizationalUnit -Name "Finance" -Path "OU=Workstations,$DomainDN"
New-ADOrganizationalUnit -Name "Standard Users" -Path "OU=Workstations,$DomainDN"
```

Create Server OUs.
```powershell
New-ADOrganizationalUnit -Name "Member Servers" -Path "OU=Servers,$DomainDN"
New-ADOrganizationalUnit -Name "File Servers" -Path "OU=Servers,$DomainDN"
```
