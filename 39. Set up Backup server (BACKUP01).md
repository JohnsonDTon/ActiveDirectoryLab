I'll be making a dedicated VM for backup purposes only. The best design is have a dedicated physical server that do this, seperate from things you want to backup. But for this lab and budgetting issues, I'll keep them together. <br> <br>

Setting up BACKUP01. Run this on a fresh (and named) Windows Server VM that you'd making it to be your back up Server. (refer to Create Windows VM.md) <br>
Make sure the IP/DNS is configured. (refer to Configure IP.md) <br> <br>

Create a back-up drive for the server. Run on Hyper-V Host.
```powershell
New-VHD `
    -Path "E:\ActiveDirectoryLab\BACKUP01\Backup-Repo.vhdx" `
    -SizeBytes 300GB `
    -Dynamic
```

Attach it to BACKUP01
```powershell
Add-VMHardDiskDrive `
    -VMName "BACKUP01" `
    -Path "E:\ActiveDirectoryLab\BACKUP01\Backup-Repo.vhdx"
```

Verify. Run on BACKUP01.
```powershell
Get-Disk
```

Initialize Disk.
```powershell
Initialize-Disk -Number 1 -PartitionStyle GPT
New-Partition -DiskNumber 1 -UseMaximumSize -DriveLetter E
Format-Volume -DriveLetter E -FileSystem NTFS -NewFileSystemLabel "Backup-Repo"
```

Verify.
```powershell
Get-Volume
```

Create backup folder
```powershell
New-Item -Path "E:\Backups" -ItemType Directory
```

Download Veeam. Since I'll have 10 server VMs or less, I'll use Veeam Backup & Replication Community Edition. Plus its free!
```text
https://www.veeam.com/products/free/backup-recovery-download.html
```

Get DVD Drive of BACKUP01. Run on Hyper-V Host
```powershell
Get-VMDvdDrive -VMName "BACKUP01"
```

Mount the ISO
```powershell
Set-VMDvdDrive -VMName "BACKUP01" -Path "E:\ISO\VeeamBackup&Replication_13.1.1.18_20260904.iso"
```

Run the installer
```text
Open the mounted drive in File Explorer
Run Setup.exe
Select: Veeam Backup & Replication
Accept the license agreement
When it asks for a license file, just hit Next
Accept the default install options (including the bundled SQL Server Express)
Install -> wait -> Finish
```

Add the repository in veeam
```text
Open Veeam Backup & Replication Console
Specify backup server: localhost -> Connect (if needed)
Sign in as current user
Backup Infrastructure (bottom left)
Backup Repositories -> right click -> Add Backup Repository...
Direct attached storage -> Microsoft Windows
Server: this server (BACKUP01)
Populate
Path: E:\Backups
Load Control : Limit maximum concurrent tasks to : 2
Next next apply to finish
Finish

Change the configuration backup location to the newly created repository? - > Yes

Right click Default Backup Repository -> Remove
Delete E:\Backup
```

We need to allow veeam to have permissions to access our servers and files. The way we'll do it is creating two accounts, svc-backup-srv for local admin access to our servers, svc-backup-dc for DC01 only. That way if one is stolen, damage is limited. <br> <br>

Create member-server account. Run on DC.
```powershell
New-ADUser `
    -Name "svc-backup-srv" `
    -SamAccountName "svc-backup-srv" `
    -Path "OU=Service Accounts,DC=adlab,DC=test" `
    -AccountPassword (Read-Host -AsSecureString "Password") `
    -PasswordNeverExpires $true `
    -Enabled $true
```

Create the Security Group that hold local-admin for member servers
```powershell
New-ADGroup `
    -Name "Backup-Server-Admins" `
    -GroupScope Global `
    -GroupCategory Security `
    -Path "OU=Service Accounts,DC=adlab,DC=test"
```

Add
```powershell
Add-ADGroupMember `
    -Identity "Backup-Server-Admins" `
    -Members "svc-backup-srv"
```

Create domain controller account.
```powershell
New-ADUser `
    -Name "svc-backup-dc" `
    -SamAccountName "svc-backup-dc" `
    -Path "OU=Service Accounts,DC=adlab,DC=test" `
    -AccountPassword (Read-Host -AsSecureString "Password") `
    -PasswordNeverExpires $true `
    -Enabled $true
```

Give admin rights to this account.
```powershell
Add-ADGroupMember `
    -Identity "Administrators" `
    -Members "svc-backup-dc"
```

We'd also create a GPO to grant admin access to lower-tier servers. Refer to Configure GPO: Backup Access.md and Configure GPO: Deny Logon.md and Configure GPO: Veeam Firewall.md <br>
Make sure those 3 are configured

Add the credentials to Veeam on BACKUP01.
```text
Open the Veeam Console
Main menu (top left, 3 lines) -> Credentials and Passwords -> Datacenter Credentials
Add... -> Standard account
    Username: ADLAB\svc-backup-srv
    Password: (the password you set)
    Description: Member servers - agent management
    OK

Add... -> Standard account
    Username: ADLAB\svc-backup-dc
    Password: (the password you set)
    Description: Domain controllers - agent management
    OK

Close
```

Create the member-servers protection group. <br>
```text
Open the Veeam Console
Inventory (bottom left) -> Physical Infrastructure (the name can differ by version)
Right click -> Add Protection Group...
    Name: Lab Servers - Members
    Type: Individual computers
    Computers -> Add...
        FILE01.adlab.test
        WSUS01.adlab.test
        WEC01.adlab.test
    Credentials: ADLAB\svc-backup-srv
    Options:
        Distribution server: BACKUP01 (this server)
        Install backup agent automatically: checked
        Install changed block tracking driver: checked (if offered)
    Review -> Apply -> Finish
```

Restart the member servers at once. Run on DC. Or do it manually or whatever, just make sure to restart them.
```powershell
Restart-Computer -ComputerName "FILE01" -Force
Restart-Computer -ComputerName "WSUS01" -Force
Restart-Computer -ComputerName "WEC01" -Force
```
Rescan member servers on Veeam if needed or if it failed, it was done automatically after creating member-servers protection group. <br>

Create the domain controller protection group
```text
Open the Veeam Console
Inventory (bottom left) -> Physical Infrastructure (the name can differ by version)
Right click -> Add Protection Group...
    Name: Lab Servers - DCs
    Type: Individual computers
    Computers -> Add...
        DC01.adlab.test
    Credentials: ADLAB\svc-backup-dc
    Options: same as above
    Review -> Apply -> Finish

Restart DC01.
On Veeam Console, Physical and Cloud Infrastructure -> Lab Servers - DCs -> Right click DC01.adlab.test -> Rescan
```

Create backup job for DC01.
```text
Home -> Backup Job -> Windows computer...
    Job mode: Server
    Job type: Managed by backup server

Name: Lab Servers - DCs
    Description: DC01 daily backup

Computers -> Add... -> Protection group -> Lab Servers - DCs

Backup Mode: Entire computer

Storage:
    Backup repository: the repository you created on BACKUP01 (E:\Backups)
    Keep backps for: 14 days

Advanced (Storage tab):
    Encryption: Enable backup file encryption
    Password -> Add... -> create a password and name it "Lab Backup Encryption"

Guest Processing:
    Enable application-aware processing: checked

Schedule:
    Run the job automatically: checked
    Daily at 11:00 PM (pick a time when the lab is normally powered on)

Summary:
    Run the job when I click Finish: checked
    Finish
```

Create backup for job for FILE01 and WEC01. (Proceed after DC01 is successfully backed up)
```text
Home -> Backup Job -> Windows computer...
    Job mode: Server
    Job type: Managed by backup server

Name: Lab Servers - Members
    Description: FILE01 and WEC01 daily backup

Computers -> Add...
    Pick the individual computers: FILE01.adlab.test and WEC01.adlab.test
    (do not add WSUS01 here, it gets its own job)
    Connect using admin credentials: ADLAB\svc-backup-srv (its a dropdown to choose)

Backup Mode: Entire computer

Storage:
    Backup repository: E:\Backups repository
    Keep backps for: 14 days
    Advanced -> Storage tab -> Enable backup file encryption
        Password: Lab Backup Encryption (the one you created)

Guest Processing:
    Enable application-aware processing: checked
    Enable guest file system indexing: checked (useful on a file server, lets you search files to restore)

Schedule:
    Daily at 11:30 PM (30 minutes after the DC job so they don't overlap)

Summary:
    Run the job when I click Finish: checked
    Finish
```

Create backup for WSUS01. (Proceed after FILE01 and WEC01 is successfully backed up)
```text
Home -> Backup Job -> Windows computer...
    Job mode: Server
    Job type: Managed by backup server

Name: Lab Servers - WSUS
    Description: WSUS01 daily backup, content drive excluded

Computers -> Add... -> WSUS01.adlab.test
Connect using admin credentials: ADLAB\svc-backup-srv (its a dropdown to choose)

Backup Mode: Volume level backup

Objects:
    Backup all volumes except the following:
    Add... -> E:\

Storage:
    Backup repository: E:\Backups repository
Keep backps for: 14 days
    Advanced -> Storage tab -> Enable backup file encryption
        Password: Lab Backup Encryption

Guest Processing:
    Enable application-aware processing: checked
    Enable guest file system indexing: unchecked

Schedule:
    Daily at 12:00 AM (staggered after the other two)

Summary:
    Run the job when I click Finish: checked
```
