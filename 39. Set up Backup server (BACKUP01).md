I'll be making a dedicated VM for backup purposes only. The best design is have a dedicated physical server that do this, seperate from things you want to backup. But for this lab and budgetting issues, I'll keep them together. <br> <br>

Setting up BACKUP01. Run this on a fresh (and named) Windows Server VM that you'd making it to be your back up Server. (refer to Create Windows VM.md) <br>
Make sure the IP/DNS is configured. (refer to Configure IP.md) <br> <br>

Create a back-up drive for the server. Run on Hyper-V Host.
```powershell
New-VHD `
    -Path "E:\ActiveDirectoryLab\BACKUP01\Backup-Repo.vhdx" `
    -SizeBytes 300GB `
    -Dynamic
```

Attach it to BACKUP01
```powershell
Add-VMHardDiskDrive `
    -VMName "BACKUP01" `
    -Path "E:\ActiveDirectoryLab\BACKUP01\Backup-Repo.vhdx"
```

Verify. Run on BACKUP01.
```powershell
Get-Disk
```

Initialize Disk.
```powershell
Initialize-Disk -Number 1 -PartitionStyle GPT
New-Partition -DiskNumber 1 -UseMaximumSize -DriveLetter E
Format-Volume -DriveLetter E -FileSystem NTFS -NewFileSystemLabel "Backup-Repo"
```

Verify.
```powershell
Get-Volume
```

Create backup folder
```powershell
New-Item -Path "E:\Backups" -ItemType Directory
```

Download Veeam. Since I'll have 10 server VMs or less, I'll use Veeam Backup & Replication Community Edition. Plus its free!
```text
https://www.veeam.com/products/free/backup-recovery-download.html
```

Get DVD Drive of BACKUP01. Run on Hyper-V Host
```powershell
Get-VMDvdDrive -VMName "BACKUP01"
```

Mount the ISO
```powershell
Set-VMDvdDrive -VMName "BACKUP01" -Path "E:\ISO\<your Veeam ISO>.iso"
```

Run the installer
```text
Open the mounted drive in File Explorer
Run Setup.exe
Select: Veeam Backup & Replication
Accept the license agreement
When it asks for a license file, just hit Next
Accept the default install options (including the bundled SQL Server Express)
Install -> wait -> Finish
```
