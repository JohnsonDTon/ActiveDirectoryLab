I'll be making a dedicated VM for backup purposes only. The best design is have a dedicated physical server that do this, seperate from things you want to backup. But for this lab and budgetting issues, I'll keep them together. <br> <br>

Setting up BACKUP01. Run this on a fresh (and named) Windows Server VM that you'd making it to be your back up Server. (refer to Create Windows VM.md) <br>
Make sure the IP/DNS is configured. (refer to Configure IP.md) <br> <br>

Create a back-up drive for the server. Run on Hyper-V Host.
```powershell
New-VHD `
    -Path "E:\ActiveDirectoryLab\BACKUP01\Backup-Repo.vhdx" `
    -SizeBytes 300GB `
    -Dynamic
```

Attach it to BACKUP01
```powershell
Add-VMHardDiskDrive `
    -VMName "BACKUP01" `
    -Path "E:\ActiveDirectoryLab\BACKUP01\Backup-Repo.vhdx"
```

Verify. Run on BACKUP01.
```powershell
Get-Disk
```

Initialize Disk.
```powershell
Initialize-Disk -Number 1 -PartitionStyle GPT
New-Partition -DiskNumber 1 -UseMaximumSize -DriveLetter E
Format-Volume -DriveLetter E -FileSystem NTFS -NewFileSystemLabel "Backup-Repo"
```

Verify.
```powershell
Get-Volume
```

Create backup folder
```powershell
New-Item -Path "E:\Backups" -ItemType Directory
```

Download Veeam. Since I'll have 10 server VMs or less, I'll use Veeam Backup & Replication Community Edition. Plus its free!
```text
https://www.veeam.com/products/free/backup-recovery-download.html
```

Get DVD Drive of BACKUP01. Run on Hyper-V Host
```powershell
Get-VMDvdDrive -VMName "BACKUP01"
```

Mount the ISO
```powershell
Set-VMDvdDrive -VMName "BACKUP01" -Path "E:\ISO\VeeamBackup&Replication_13.1.1.18_20260904.iso"
```

Run the installer
```text
Open the mounted drive in File Explorer
Run Setup.exe
Select: Veeam Backup & Replication
Accept the license agreement
When it asks for a license file, just hit Next
Accept the default install options (including the bundled SQL Server Express)
Install -> wait -> Finish
```

Add the repository in veeam
```text
Open Veeam Backup & Replication Console
Specify backup server: localhost -> Connect (if needed)
Sign in as current user
Backup Infrastructure (bottom left)
Backup Repositories -> right click -> Add Backup Repository...
Direct attached storage -> Microsoft Windows
Server: this server (BACKUP01)
Populate
Path: E:\Backups
Load Control : Limit maximum concurrent tasks to : 2
Next next apply to finish
Finish

Change the configuration backup location to the newly created repository? - > Yes

Right click Default Backup Repository -> Remove
Delete E:\Backup
```

We need to allow veeam to have permissions to access our servers and files. The way we'll do it is creating two accounts, svc-backup-srv for local admin access to our servers, svc-backup-dc for DC01 only. That way if one is stolen, damage is limited. <br> <br>

Create member-server account. Run on DC.
```powershell
New-ADUser `
    -Name "svc-backup-srv" `
    -SamAccountName "svc-backup-srv" `
    -Path "OU=Service Accounts,DC=adlab,DC=test" `
    -AccountPassword (Read-Host -AsSecureString "Password") `
    -PasswordNeverExpires $true `
    -Enabled $true
```

Create the Security Group that hold local-admin for member servers
```powershell
New-ADGroup `
    -Name "Backup-Server-Admins" `
    -GroupScope Global `
    -GroupCategory Security `
    -Path "OU=Service Accounts,DC=adlab,DC=test"
```

Add
```powershell
Add-ADGroupMember `
    -Identity "Backup-Server-Admins" `
    -Members "svc-backup-srv"
```

We'd also create a GPO to grant admin access to lower-tier servers. Refer to Configure GPO: Backup Access.md and Configure GPO: Deny Logon.md
<br> <br>

Create domain controller account.
```powershell
New-ADUser `
    -Name "svc-backup-dc" `
    -SamAccountName "svc-backup-dc" `
    -Path "OU=Service Accounts,DC=adlab,DC=test" `
    -AccountPassword (Read-Host -AsSecureString "Password") `
    -PasswordNeverExpires $true `
    -Enabled $true
```

Give admin rights to this account.
```powershell
Add-ADGroupMember `
    -Identity "Administrators" `
    -Members "svc-backup-dc"
```
