I'll be making a dedicated VM for backup purposes only. The best design is have a dedicated physical server, seperate from things you want to backup. But for this lab and budgetting issues, I'll keep them together. <br> <br>

Setting up BACKUP01. Run this on a fresh (and named) Windows Server VM that you'd making it to be your back up Server. (refer to Create Windows VM.md) <br>
Make sure the IP/DNS is configured. (refer to Configure IP.md) <br> <br>


Download Veeam. Since I'll have 10 server VMs or less, I'll use Veeam Backup & Replication Community Edition. Plus its free!
```text
https://www.veeam.com/products/free/backup-recovery-download.html
```

Create a folder for the backups. Run on Hyper-V host. <br>
I use the same disk where I store my VMs so I can bring my VMs around. This is not real protection against hard-disk failure, so in enterprise make sure the location is different.
```powershell
New-Item -Path "E:\VeeamBackups" -ItemType Directory
```

Install Veeam on the Hyper-V host
```powershell
Mount-DiskImage -ImagePath "E:\ISO\VeeamBackup&Replication_13.1.1.18_20260904.iso"
```

Run the installer
```text
Open the mounted drive in File Explorer
Run Setup.exe
Select: Veeam Backup & Replication
Accept the license agreement
When it asks for a license file, just hit Next
Accept the default install options (including the bundled SQL Server Express)
Install -> wait -> Finish
```
