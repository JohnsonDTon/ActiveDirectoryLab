Create VM. </br>
Name the VM, Set the Generation, set the directory path where you'd keep the VM, set HD size (its dynamic), set switch name.</br>
```powershell
New-VM `
    -Name "DC01" `
    -Generation 2 `
    -NewVHDPath "E:\ActiveDirectoryLab\DC01\DC01.vhdx" `
    -NewVHDSizeBytes 80GB `
    -SwitchName "Internal"
```
