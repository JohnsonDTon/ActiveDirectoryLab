Review and change the settings based on your environment and intentions. </br></br>

Create Switch for VM.
```powershell
New-VMSwitch -Name "AD-Lab-Internal" -SwitchType Internal
```

Create VM. </br>
Name the VM, Set the Generation, set the directory path where you'd keep the VM, set HD size (its dynamic), set switch name.
```powershell
New-VM `
    -Name "DC01" `
    -Generation 2 `
    -NewVHDPath "E:\ActiveDirectoryLab\DC01\DC01.vhdx" `
    -NewVHDSizeBytes 80GB `
    -SwitchName "AD-Lab-Internal"
```
