Review and change the settings based on your environment and intentions. </br></br>

Variables for names I'll use.
```powershell
$SwitchName = "AD-Lab-Internal"
$VMName = "DC01"
$VHDPath = "E:\ActiveDirectoryLab\DC01\DC01.vhdx"
$ISOPath = "E:\ISO\Window Server 2025.iso"
```

Create Switch for VM.
```powershell
New-VMSwitch -Name $SwitchName -SwitchType Internal
```

Create VM. </br>
Name the VM, Set the Generation, set the directory path where you'd keep the virtual hard disk, set HD size (its dynamic), set switch name.
```powershell
New-VM `
    -Name $VMName `
    -Generation 2 `
    -NewVHDPath $VHDPath `
    -NewVHDSizeBytes 80GB `
    -SwitchName $SwitchName
```
<br>

Set Number of Processor for the VM. </br>
```powershell
Set-VMProcessor -VMName $VMName -Count 2
```
<br>

Set RAM for the VM.
```powershell
Set-VMMemory `
    -VMName $VMName `
    -DynamicMemoryEnabled $true `
    -MinimumBytes 2GB `
    -StartupBytes 4GB `
    -MaximumBytes 8GB
```
<br>

Set Secure Boot On. <br>
This is optional, but in enterprise setting, its highly probable you're working with Secure Boot On anyways.
```powershell
Set-VMFirmware -VMName $VMName -EnableSecureBoot On
```
<br>

Turn Checkpoints (snapshots) off. <br>
This is optional, prefer to use planned backups on my own so keeping it disabled for this lab.
```powershell
Set-VM -Name $VMName -CheckpointType Disabled
```
<br>

Check Checkpoint settings
```powershell
Get-VM -Name $VMName | Select-Object Name, CheckpointType
```
<br>

Check if you have VM DVD Drive.<br>
Need this to install OS on VM.
```powershell
Get-VMDvdDrive -VMName $VMName
```
<br>

Add VM DVD Drive, do if you don't have it.
```powershell
Add-VMDvdDrive -VMName $VMName
```
<br>

Mount the ISO file to the VM. <br>
```powershell
Set-VMDvdDrive `
    -VMName $VMName `
    -Path $ISOPath
```
<br>

Start up the VM.
```powershell
Start-VM -Name $VMName
```
<br>

Open the VM in a different window. Do this after you started it up.
```powershell
vmconnect.exe localhost $VMName
```
<br>

Run the OS Installation. <br><br>

Un-mount the ISO file from the VM. <br>
This is good practice to do after you finish the OS Installation.
```powershell
Set-VMDvdDrive -VMName $VMName -Path $null
```
<br>

Check if VM has any ISOs mounted.
```powershell
Get-VMDvdDrive -VMName $VMName
```
<br>

Rename Computer to DC01 for consistency. Run this in the VM.
```powershell
Rename-Computer -NewName $VMName
Restart-Computer
```
