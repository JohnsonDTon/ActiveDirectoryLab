Review and change the settings based on your environment and intentions. </br></br>

Create Switch for VM.
```powershell
New-VMSwitch -Name "AD-Lab-Internal" -SwitchType Internal
```

Create VM. </br>
Name the VM, Set the Generation, set the directory path where you'd keep the virtual hard disk, set HD size (its dynamic), set switch name.
```powershell
New-VM `
    -Name "DC01" `
    -Generation 2 `
    -NewVHDPath "E:\ActiveDirectoryLab\DC01\DC01.vhdx" `
    -NewVHDSizeBytes 80GB `
    -SwitchName "AD-Lab-Internal"
```
<br>

Set-VMProcessor -VMName $VMName -Count 2

Set Number of Processor for the VM. </br>
```powershell
Set-VMProcessor -VMName "DC01" -Count 2
```
<br>

Set RAM for the VM.
```powershell
Set-VMMemory `
    -VMName "DC01" `
    -DynamicMemoryEnabled $true `
    -MinimumBytes 2GB `
    -StartupBytes 4GB `
    -MaximumBytes 8GB
```
<br>

Set Secure Boot On. <br>
This is optional, but in enterprise setting, its highly probable you're working with Secure Boot On anyways.
```powershell
Set-VMFirmware -VMName "DC01" -EnableSecureBoot On
```
<br>

Turn Checkpoints (snapshots) off. <br>
This is optional, prefer to use planned backups on my own so keeping it disabled for this lab.
```powershell
Set-VM -Name "DC01" -CheckpointType Disabled
```
<br>

Check Checkpoint settings
```powershell
Get-VM -Name "DC01" | Select-Object Name, CheckpointType
```
<br>

Mount the ISO file to the VM. <br>
Add-VMDvdDrive may not be necessary if you already have VMDvdDrive, but this assumes you don't.
```powershell
Add-VMDvdDrive -VMName "DC01"
Set-VMDvdDrive `
    -VMName "DC01" `
    -Path "D:\Files\ISO\Window Server 2025.iso"
```
<br>

Start up the VM.
```powershell
Start-VM -Name "DC01"
```
<br>

Open the VM in a different window. Do this after you started it up.
```powershell
vmconnect.exe localhost DC01
```
<br>

Un-mount the ISO file from the VM. <br>
This is good practice to do after you finish the OS Installation.
```powershell
Set-VMDvdDrive -VMName "DC01" -Path $null
```
<br>

Check if VM has any ISOs mounted.
```powershell
Get-VMDvdDrive -VMName "DC01"
```
