Windows Local Administrator Password Solution (Windows LAPS) is a native security feature that automatically manages, rotates, and securely backs up passwords for local administrator accounts on Windows devices. <br>
This is essential for enterprise security, wouldn't want someone to able to gain admin rights to your workstations because they were able to break into the local admin account, right? <br> <br>

Extend the AD schema. <br>
This adds LAPS attributes to AD, which is essential to what we need to do.
```powershell
Update-LapsADSchema
```

Allow client workstations to update their own LAPS password. Need this for our GPO to work
```powershell
Set-LapsADComputerSelfPermission `
    -Identity "OU=Workstations,DC=adlab,DC=test"
```

Allow security group 'GG-IT-Admins' to be able to retrieve LAPS passwords in Workstations OU
```powershell
Set-LapsADReadPasswordPermission `
    -Identity "OU=Workstations,DC=adlab,DC=test" `
    -AllowedPrincipals "ADLAB\GG-IT-Admins"
```

Create GPO and link to OU.
```powershell
New-GPO -Name "Workstations - Windows LAPS"

New-GPLink `
    -Name "Workstations - Windows LAPS" `
    -Target "OU=Workstations,DC=adlab,DC=test"
```

Configure LAPS to back up passwords to AD
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Windows LAPS" `
    -Key "HKLM\SOFTWARE\Microsoft\Policies\LAPS" `
    -ValueName "BackupDirectory" `
    -Type DWord `
    -Value 2
```

Configure password complexity <br>
This option enables LAPS to include random mix of character types
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Windows LAPS" `
    -Key "HKLM\SOFTWARE\Microsoft\Policies\LAPS" `
    -ValueName "PasswordComplexity" `
    -Type DWord `
    -Value 4
```

Set password length
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Windows LAPS" `
    -Key "HKLM\SOFTWARE\Microsoft\Policies\LAPS" `
    -ValueName "PasswordLength" `
    -Type DWord `
    -Value 24
```

Set password age. <br>
Will do 30 days, this mean password gets rotated every 30 days.
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Windows LAPS" `
    -Key "HKLM\SOFTWARE\Microsoft\Policies\LAPS" `
    -ValueName "PasswordAgeDays" `
    -Type DWord `
    -Value 30
```

Set to manage local 'Administrator' account
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Windows LAPS" `
    -Key "HKLM\SOFTWARE\Microsoft\Policies\LAPS" `
    -ValueName "AdministratorAccountName" `
    -Type String `
    -Value "Administrator"
```

Enable automatic password management with encryption
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Windows LAPS" `
    -Key "HKLM\SOFTWARE\Microsoft\Policies\LAPS" `
    -ValueName "ADPasswordEncryptionEnabled" `
    -Type DWord `
    -Value 1
```
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Windows LAPS" `
    -Key "HKLM\SOFTWARE\Microsoft\Policies\LAPS" `
    -ValueName "ADPasswordEncryptionPrincipal" `
    -Type String `
    -Value "ADLAB\GG-IT-Admins"
```

Verify on client workstation
```powershell
gpupdate /force
```
```powershell
Get-LapsDiagnostics
```

Trigger a LAPS password update. Run on client workstation
```powershell
Invoke-LapsPolicyProcessing
```
```powershell
Get-LapsADPassword `
    -Identity "WIN11-01" `
    -AsPlainText
```
