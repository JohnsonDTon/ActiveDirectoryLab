This GPO we create will automatically map Network Drives for users. <br> <br>
```text
User Accounts OU
└── Users - Network Drives
    │
    ├── I: → \\FILE01\IT
    │      └── GG-IT-Users
    │
    ├── H: → \\FILE01\HR
    │      └── GG-HR-Users
    │
    ├── F: → \\FILE01\Finance
    │      └── GG-Finance-Users
    │
    └── P: → \\FILE01\Public
           └── GG-All-Employees
```

Create GPO and link to OU.
```powershell
New-GPO -Name "Users - Network Drives"

New-GPLink `
    -Name "Users - Network Drives" `
    -Target "OU=User Accounts,DC=adlab,DC=test"
```

On a DC, Open Group Policy Management.
```text
Right click 'Users - Network Drives' -> Edit...
User Configuration
└── Preferences
    └── Windows Settings
        └── Drive Maps
```

Map Public Drive.
```text
Right-click Drive Maps → New → Mapped Drive.
Fill 'New Drive Properties' window with below.

Action:   Update
Location: \\FILE01\Public
Drive Letter, Use:    P
Checkbox Reconnect:
```

Map IT Drive
```text
Right-click Drive Maps → New → Mapped Drive.
Fill 'New Drive Properties' window with below.

Action:   Update
Location: \\FILE01\IT
Drive:    I:
Checkbox Reconnect:
```
```text
Common
Checkbox Item-level targeting
Targeting...
New Item
Security Group
...
Select Group: GG-IT-Users
Check Names
OK
```
