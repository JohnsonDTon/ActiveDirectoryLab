To create Active Directory Lab, first you need a virtualization platform. I am going with Hyper-V. </br>
PS: Make sure to use a OS that supports Hyper-V, I used Windows 11 Pro </br> </br>

Enable Hyper-V Manager. </br>
Computer will restart once you run cmdlet.</br>
```powershell
Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V -All
```
<br>

Check if Hyper-V is installed.</br>
```powershell
Get-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V
```
