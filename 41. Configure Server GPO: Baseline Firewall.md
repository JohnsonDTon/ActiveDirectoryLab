Create GPO and link to OU
```powershell
New-GPO `
    -Name "Servers - Baseline Firewall" `
    -Comment "Firewall state, logging, ping from lab subnet and remote management from DC01"

New-GPLink `
    -Name "Servers - Baseline Firewall" `
    -Target "OU=Servers,DC=adlab,DC=test" `
    -LinkEnabled Yes
```

Turn firewall on, block inbound by default, allow outbound by default, allow local firewall rules
```powershell
Set-NetFirewallProfile `
    -PolicyStore "adlab.test\Servers - Baseline Firewall" `
    -Profile Domain,Private,Public `
    -Enabled True `
    -DefaultInboundAction Block `
    -DefaultOutboundAction Allow `
    -AllowLocalFirewallRules True
```

Configure Firewall logging for all profiles
```powershell
Set-NetFirewallProfile `
    -PolicyStore "adlab.test\Servers - Baseline Firewall" `
    -Profile Domain,Private,Public `
    -LogBlocked True `
    -LogAllowed False `
    -LogMaxSizeKilobytes 16384 `
    -LogFileName "%SystemRoot%\System32\LogFiles\Firewall\pfirewall.log"
```

Allow servers to respond to pings, only from my lab subnet and the server is on a domain profile
```powershell
New-NetFirewallRule `
    -DisplayName "Baseline - ICMP Echo from Lab Subnet" `
    -PolicyStore "adlab.test\Servers - Baseline Firewall" `
    -Direction Inbound `
    -Action Allow `
    -Profile Domain `
    -Protocol ICMPv4 `
    -IcmpType 8 `
    -RemoteAddress 192.168.100.0/24
```

Enable remote management from DC01
```powershell
New-NetFirewallRule `
    -DisplayName "Baseline - Remote Management from DC01" `
    -PolicyStore "adlab.test\Servers - Baseline Firewall" `
    -Direction Inbound `
    -Action Allow `
    -Profile Domain `
    -Protocol TCP `
    -LocalPort 135,445,49152-65535 `
    -RemoteAddress 192.168.100.10
```

Verify. Run on WEC01
```powershell

```
