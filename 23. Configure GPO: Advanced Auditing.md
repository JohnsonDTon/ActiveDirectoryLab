Unfortunately this one is proven difficult to do via PowerShell as theres no Auditing powershell GPO cmdlets. (or atleast, idk it) <br>
I will be configuring this one via GUI mostly. Writing down notes how I did it so I can revisit this in the future when needed <br>

Create GPO and link to OU. Run on DC
```powershell
New-GPO -Name "Workstations - Auditing"

New-GPLink `
    -Name "Workstations - Auditing" `
    -Target "OU=Workstations,DC=adlab,DC=test"
```

To go to configuration:
```text
Go to a DC, Group Policy Management
Under Workstations OU, right click 'Workstations - Auditing'
Edit...

Computer Configuration
└── Policies
    └── Windows Settings
        └── Security Settings
            └── Advanced Audit Policy Configuration
                └── Audit Policies
```

Configure account logon auditing: Track Credential validation <br>
Whenever a user account logs in, logs both success + failure validation (like incorrect pw)
```text
Account Logon → Audit Credential Validation

Select:

☑ Configure the following audit events
☑ Success
☑ Failure
```

Track Logon sessions, works conjunction with credential validation
```text
Logon/Logoff → Audit Logon
☑ Configure the following audit events
☑ Success
☑ Failure
```

Track Logoff sessions
```text
Logon/Logoff → Audit Logoff

Select:

☑ Configure the following audit events
☑ Success
```

Monitors changes made to the Windows Security audit policy itself. Useful to see if an attacker is trying to disable your auditing settings
