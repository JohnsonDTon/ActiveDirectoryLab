This is continuation of Configure GPO: RDP page. So you'd have 'Workstations - RDP' GPO.

Create RDP Security Group. Run on DC.
```powershell
New-ADGroup `
    -Name "GG-Workstation-RDP-Users" `
    -GroupScope Global `
    -GroupCategory Security `
    -Path "OU=Global,OU=Security Groups,DC=adlab,DC=test"
```

Add user to group
```powershell
Add-ADGroupMember `
    -Identity "GG-Workstation-RDP-Users" `
    -Members "alice.johnson"
```

Give this security group access to RDP
```text
Open Group Policy Management.

Workstations - RDP (right click edit)
└── Computer Configuration
    └── Preferences
        └── Control Panel Settings
            └── Local Users and Groups

Right click, New -> Local Group
Action: Update
Group name: Remote Desktop Users
Add... -> ... -> ADLAB\GG-Workstation-RDP-Users
```

Go try to RDP. It should work.
