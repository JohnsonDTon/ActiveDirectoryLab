Create GPO and link to OU.
```powershell
New-GPO `
    -Name "Servers - Microsoft Defender" `
    -Comment "Defender real-time and cloud protection, scheduled scans, signatures from WSUS01, ASR in audit mode"

New-GPLink `
    -Name "Servers - Microsoft Defender" `
    -Target "OU=Servers,DC=adlab,DC=test" `
    -LinkEnabled Yes
```

Turn on real-time protection
```powershell
Set-GPRegistryValue `
    -Name "Servers - Microsoft Defender" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender\Real-Time Protection" `
    -ValueName "DisableRealtimeMonitoring" -Type DWord -Value 0
```

Turn on cloud-delivered protection. Talks to Microsoft Servers about new Malware that local signature may be slow on.
```powershell
Set-GPRegistryValue `
    -Name "Servers - Microsoft Defender" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender\Spynet" `
    -ValueName "SpynetReporting" -Type DWord -Value 2
```

Disable sending sample files to Microsoft
```powershell
Set-GPRegistryValue `
    -Name "Servers - Microsoft Defender" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender\Spynet" `
    -ValueName "SubmitSamplesConsent" -Type DWord -Value 2
```
