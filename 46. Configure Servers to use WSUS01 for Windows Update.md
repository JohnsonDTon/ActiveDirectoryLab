Check what groups are already in WSUS01. Run in WSUS01.
```powershell
(Get-WsusServer).GetComputerTargetGroups() |
    Select-Object Name
```

If Servers is missing from above, create it
```powershell
(Get-WsusServer).CreateComputerTargetGroup("Servers")
```

Set to let GPO choose the group (Should be enabled, but double-check)
```text
'Windows Servers Update Services' Console -> WSUS01 dropdown -> Options -> Computers (in middle pane)
    Use Group Policy or registry settings on computers
    OK
```

Check Display Version of the Windows Server 2025 you use. Mine is 24H2
```powershell
Get-ItemProperty `
    -Path "HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion" |
    Select-Object ProductName, DisplayVersion, CurrentBuild, UBR
```

Sync Windows Server 2025 Updates.
```text
WSUS console -> Options -> Products and Classifications -> Products
    Tick the Microsoft Server Operating System-24H2 entry (do your version)
Classifications:
    Critical Updates, Security Updates, Updates (same as the workstation setup)
OK
Synchronizations -> Synchronize Now
```
