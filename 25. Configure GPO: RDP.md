This GPO will configure to allow RDP on our workstations to remote in. <br>
This way in a real-world environment, IT can provide technical support remotely <br> <br>

Create GPO and link to OU. Run on DC
```powershell
New-GPO -Name "Workstations - RDP"

New-GPLink `
    -Name "Workstations - RDP" `
    -Target "OU=Workstations,DC=adlab,DC=test"
```

Enable Remote Desktop
```powershell
Set-GPRegistryValue `
    -Name "Workstations - RDP" `
    -Key "HKLM\SYSTEM\CurrentControlSet\Control\Terminal Server" `
    -ValueName "fDenyTSConnections" `
    -Type DWord `
    -Value 0
```

Require Network Level Authentication (NLA) <br>
NLA uses domain authentication mechanisms before establishing the full interactive session. Mainly security purposes.
```powershell
Set-GPRegistryValue `
    -Name "Workstations - RDP" `
    -Key "HKLM\SYSTEM\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp" `
    -ValueName "UserAuthentication" `
    -Type DWord `
    -Value 1
```

Enable Shadowing remote
```powershell
Set-GPRegistryValue `
    -Name "Workstations - RDP" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows NT\Terminal Services" `
    -ValueName "Shadow" `
    -Type DWord `
    -Value 1
```

Allow RDP through Windows Firewall. <br>
This assumes you have a GPO for firewall 'Workstations - Firewall'
```powershell
New-NetFirewallRule `
    -DisplayName "Allow RDP - TCP 3389" `
    -Description "Allow inbound Remote Desktop connections from the domain network." `
    -Direction Inbound `
    -Protocol TCP `
    -LocalPort 3389 `
    -Action Allow `
    -Profile Domain `
    -Enabled True `
    -PolicyStore "adlab.test\Workstations - Firewall"
```
Verify Firewall rule
```powershell
Get-NetFirewallRule `
    -PolicyStore "adlab.test\Workstations - Firewall" `
    -DisplayName "Allow RDP - TCP 3389" |
    Select-Object DisplayName, Enabled, Direction, Action, Profile
```

Allow RPC Endpoint Mapper <br>
We use this to remotely diagnose endpoint info remotely.
```powershell
New-NetFirewallRule `
    -DisplayName "Allow RPC Endpoint Mapper - TCP 135" `
    -Description "Allow inbound RPC Endpoint Mapper traffic for remote Windows administration." `
    -Direction Inbound `
    -Protocol TCP `
    -LocalPort 135 `
    -Action Allow `
    -Profile Domain `
    -Enabled True `
    -PolicyStore "adlab.test\Workstations - Firewall"
```
Verify Firewall rule
```powershell
Get-NetFirewallRule `
    -PolicyStore "adlab.test\Workstations - Firewall" `
    -DisplayName "Allow RPC Endpoint Mapper - TCP 135" |
    Select-Object DisplayName, Enabled, Direction, Action, Profile
```
