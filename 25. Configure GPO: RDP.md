This GPO will configure to allow RDP on our workstations to remote in. <br>
This way in a real-world environment, IT can provide technical support remotely <br> <br>

Create GPO and link to OU. Run on DC
```powershell
New-GPO -Name "Workstations - RDP"

New-GPLink `
    -Name "Workstations - RDP" `
    -Target "OU=Workstations,DC=adlab,DC=test"
```

Enable Remote Desktop
```powershell
Set-GPRegistryValue `
    -Name "Workstations - RDP" `
    -Key "HKLM\SYSTEM\CurrentControlSet\Control\Terminal Server" `
    -ValueName "fDenyTSConnections" `
    -Type DWord `
    -Value 0
```

Require Network Level Authentication (NLA) <br>
NLA uses domain authentication mechanisms before establishing the full interactive session. Mainly security purposes.
```powershell
Set-GPRegistryValue `
    -Name "Workstations - RDP" `
    -Key "HKLM\SYSTEM\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp" `
    -ValueName "UserAuthentication" `
    -Type DWord `
    -Value 1
```

Allow RDP through Windows Firewall. <br>
This assumes you have a GPO for firewall 'Workstations - Firewall'
```powershell
Set-NetFirewallRule `
    -DisplayGroup "Remote Desktop" `
    -Enabled True `
    -Profile Domain `
    -PolicyStore "adlab.test\Workstations - Firewall"
```

Verify on client workstation
```powershell
gpupdate /force
```
```powershell
Get-Service TermService
```
```powershell
Get-NetTCPConnection -LocalPort 3389 -State Listen
```
