This GPO works in conjunction with 'Workstations - Advanced Auditing' GPO. That one decides what Windows record (successfuly log in, failed log in, process starts, a user/group change, etc) <br>
This GPO decides how much room Windows gives those records and what happens when the logs fill up. <br> <br>

Create and link the GPO
```powershell
New-GPO -Name "Workstations - Event Logging"

New-GPLink `
    -Name "Workstations - Event Logging" `
    -Target "OU=Workstations,DC=adlab,DC=test"
```

Configure the Security log size (128mb)
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Event Logging" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\EventLog\Security" `
    -ValueName "MaxSize" `
    -Type DWord `
    -Value 131072
```

Configure Security log to overwrite older events when the log reaches its limit
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Event Logging" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\EventLog\Security" `
    -ValueName "Retention" `
    -Type DWord `
    -Value 0
```

