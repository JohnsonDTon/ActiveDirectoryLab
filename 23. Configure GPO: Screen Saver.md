Unattended access on computers is a security risk. Do screen saver + password protection along with Screen lock gpo <br>
Reference: https://github.com/JohnsonDTon/ActiveDirectoryLab/blob/main/19.%20Configure%20GPO%3A%20Screen%20Lock.md <br> <br>

Create and link the GPO
```powershell
New-GPO -Name "Users - Screen Saver"

New-GPLink `
    -Name "Users - Screen Saver" `
    -Target "OU=User Accounts,DC=adlab,DC=test"
```

Enable screen saver
```powershell
Set-GPRegistryValue `
    -Name "Users - Screen Saver" `
    -Key "HKCU\Software\Policies\Microsoft\Windows\Control Panel\Desktop" `
    -ValueName "ScreenSaveActive" `
    -Type String `
    -Value "1"
```

Require authentication when exiting screen saver
```powershell
Set-GPRegistryValue `
    -Name "Users - Screen Saver" `
    -Key "HKCU\Software\Policies\Microsoft\Windows\Control Panel\Desktop" `
    -ValueName "ScreenSaverIsSecure" `
    -Type String `
    -Value "1"
```

Set timeout to 900 seconds (do it the same as your Screen Lock GPO)
```powershell
Set-GPRegistryValue `
    -Name "Users - Screen Saver" `
    -Key "HKCU\Software\Policies\Microsoft\Windows\Control Panel\Desktop" `
    -ValueName "ScreenSaveTimeOut" `
    -Type String `
    -Value "900"
```

Verify.
```powershell
Get-GPRegistryValue `
    -Name "Users - Screen Saver" `
    -Key "HKCU\Software\Policies\Microsoft\Windows\Control Panel\Desktop"
```

Verify on client
```powershell
gpupdate /force
```
```powershell
gpresult /r /scope user
```
```powershell
Get-ItemProperty `
    -Path "HKCU:\Software\Policies\Microsoft\Windows\Control Panel\Desktop" `
    -Name ScreenSaveActive, ScreenSaverIsSecure, ScreenSaveTimeOut
```
