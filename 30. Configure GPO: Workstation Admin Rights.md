This assumes you made global security group '"GG-IT-Admins"' <br>
This assumes you made a user account you'd want to configure as admin and added to the security group(3alice.johnson). <br>

Create GPO and link to OU.
```powershell
New-GPO -Name "Workstations - Local Administrators"

New-GPLink `
    -Name "Workstations - Local Administrators" `
    -Target "OU=Workstations,DC=adlab,DC=test"
```

Assign Global Security Group 'GG-IT-Admins' to this GPO. <br>
When you name the Group name below as 'Administrators (built-in)'. Windows Server knows local admin rights.
```text
Group Policy Management
Right Click 'Workstations - Local Administrators' -> Edit...

Computer Configuration
└── Preferences
    └── Control Panel Settings
        └── Local Users and Groups

Right-click Local Users and Groups → New → Local Group.

Action: Update
Group name: Administrators (built-in)
Add member:
ADLAB\GG-IT-Admins
```

Verify running powershell as admin with a GG-IT-Admins member. Restart computer made it work for me if you run into issues.
