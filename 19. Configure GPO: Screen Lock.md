For security measure, you'd want to lock the screen after inactivity <br>
Wouldn't want to keep your PC open for use after you walk away. <br> <br>

Create and link the GPO. Run on DC.
```powershell
New-GPO -Name "Workstations - Screen Lock"

New-GPLink `
    -Name "Workstations - Screen Lock" `
    -Target "OU=Workstations,DC=adlab,DC=test"
```
