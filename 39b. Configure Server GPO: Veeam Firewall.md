Create GPO and link to OU
```powershell
New-GPO `
    -Name "Servers - Veeam Firewall" `
    -Comment "Allows Veeam management traffic from BACKUP01 only"

New-GPLink `
    -Name "Servers - Veeam Firewall" `
    -Target "OU=Servers,DC=adlab,DC=test" `
    -LinkEnabled Yes

New-GPLink `
    -Name "Servers - Veeam Firewall" `
    -Target "OU=Domain Controllers,DC=adlab,DC=test" `
    -LinkEnabled Yes
```

Open port 135,445, 49152-65535, 6160,6162,10006 from 192.168.100.5 (BACKUP01) <br>
```powershell
New-NetFirewallRule `
    -DisplayName "Veeam - SMB and RPC from BACKUP01" `
    -PolicyStore "adlab.test\Servers - Veeam Firewall" `
    -Direction Inbound `
    -Action Allow `
    -Profile Domain `
    -Protocol TCP `
    -LocalPort 135,445 `
    -RemoteAddress 192.168.100.5
```
```powershell
New-NetFirewallRule `
    -DisplayName "Veeam - Dynamic RPC from BACKUP01" `
    -PolicyStore "adlab.test\Servers - Veeam Firewall" `
    -Direction Inbound `
```
