Create and link the GPO. Run on DC.
```powershell
New-GPO -Name "Workstations - Defender"

New-GPLink `
    -Name "Workstations - Defender" `
    -Target "OU=Workstations,DC=adlab,DC=test"
```

Enable Real-Time Monitoring <br>
Windows Defender will continuously watch files and activity while Windows is running
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Defender" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender\Real-Time Protection" `
    -ValueName "DisableRealtimeMonitoring" `
    -Type DWord `
    -Value 0
```

Enable behavior monitoring <br>
Windows Defender will watch what programs are doing and flags it if somethings off

```powershell
Set-GPRegistryValue `

    -ValueName "DisableBehaviorMonitoring" `
    -Type DWord `
    -Value 0
```

Enable on-access protection <br>
Windows Defender protects when files are accessed. If malicious->Block, Not malicious->allow.
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Defender" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender\Real-Time Protection" `
    -ValueName "DisableOnAccessProtection" `
    -Type DWord `
    -Value 0
```

Enable Internet-Originated Antimalware Validation (IOAV) protection <br>
Windows Defender scans files that came from the internet
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Defender" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender\Real-Time Protection" `
    -ValueName "DisableIOAVProtection" `
    -Type DWord `
    -Value 0
```

Enable cloud-delivered protection <br>
Because malware is constantly evolving, Windows Defender also checks Microsoft Cloud's database to check if a suspicious file is malicious
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Defender" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender\Spynet" `
    -ValueName "SpynetReporting" `
    -Type DWord `
    -Value 2
```

Disable sample collection <br>
This sends sample of your file data to analyze it. Best to not send third-party companies your data unless needed.
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Defender" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender\Spynet" `
    -ValueName "SubmitSamplesConsent" `
    -Type DWord `
    -Value 0
```

Enable Potentially unwanted Application (PUA) <br>
This blocks 'Not necessarily malware, but potentially unwanted' apps. Like bloatware that came with an app
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Defender" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender" `
    -ValueName "PUAProtection" `
    -Type DWord `
    -Value 1
```

Enable Cloud Block level <br>
Makes Windows Defender more aggressive in blocking by checking with cloud intelligence. Best to block and check than be sorry.
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Defender" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender\MpEngine" `
    -ValueName "MpCloudBlockLevel" `
    -Type DWord `
    -Value 2
```

Schedule quick scan <br>
120 in this is 2:00 AM daily
```powershell

    -Name "Workstations - Defender" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender\Scan" `

```
