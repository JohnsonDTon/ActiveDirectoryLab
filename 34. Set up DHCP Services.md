We'll configure DHCP on our DCs. <br>

Install the DHCP role. Run on DC01 and DC02.
```powershell
Install-WindowsFeature DHCP -IncludeManagementTools
```

Create the DHCP Security Group and restart service. Run on DC01 and DC02. <br>
This creates the local DHCP Administrators and DHCP Users groups, which the role needs.
```powershell
Add-DhcpServerSecurityGroup
Restart-Service dhcpserver
```

Authorize both servers in AD. Run on DC01
```powershell
Add-DhcpServerInDC -DnsName "DC01.adlab.test" -IPAddress 192.168.100.10
Add-DhcpServerInDC -DnsName "DC02.adlab.test" -IPAddress 192.168.100.11
```

Verify. Should see both dc01 and dc02.
```powershell
Get-DhcpServerInDC
```

Create DHCP Scope. Run on DC01.
```powershell
Add-DhcpServerv4Scope `
    -Name "AD-Lab" `
    -StartRange 192.168.100.50 `
    -EndRange 192.168.100.254 `
    -SubnetMask 255.255.255.0 `
    -State Active
```

Set the scope options
```powershell
Set-DhcpServerv4OptionValue `
    -ScopeId 192.168.100.0 `
    -Router 192.168.100.1 `
    -DnsServer 192.168.100.10,192.168.100.11 `
    -DnsDomain "adlab.test"
```

Configure DHCP failover/load balancing. Set a Shared Secret password.
```powershell
Add-DhcpServerv4Failover `
    -ComputerName "DC01.adlab.test" `
    -PartnerServer "DC02.adlab.test" `
    -Name "DC01-DC02-Failover" `
    -ScopeId 192.168.100.0 `
    -LoadBalancePercent 50 `
    -SharedSecret "YourSecretHere" `
    -AutoStateTransition $true
```

Switch clients to DHCP. Run on WIN11-01 and WIN11-02 <br>
You want to remove the net-route because it might be configured statically, you want it managed via DHCP. It will error out if its not configured, in any  case its harmless to run.
```powershell
Remove-NetRoute -InterfaceAlias "Ethernet" -DestinationPrefix "0.0.0.0/0" -Confirm:$false
Set-NetIPInterface -InterfaceAlias "Ethernet" -Dhcp Enabled
Set-DnsClientServerAddress -InterfaceAlias "Ethernet" -ResetServerAddresses
ipconfig /renew
```
Verify
```powershell
Get-NetIPInterface -InterfaceAlias "Ethernet" -AddressFamily IPv4 | Select-Object InterfaceAlias, Dhcp
```


Check if failover DHCP knows when WIN11-01 lease expires. It should and should match.
```powershell
Get-DhcpServerv4Lease -ScopeId 192.168.100.0 | Select-Object IPAddress, HostName, ClientId, LeaseExpiryTime
```


