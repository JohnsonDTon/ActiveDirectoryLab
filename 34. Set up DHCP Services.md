We'll configure DHCP on our DCs. <br>

Install the DHCP role. Run on DC01 and DC02.
```powershell
Install-WindowsFeature DHCP -IncludeManagementTools
```

Create the DHCP Security Group and restart service. Run on DC01 and DC02. <br>
This creates the local DHCP Administrators and DHCP Users groups, which the role needs.
```powershell
Add-DhcpServerSecurityGroup
Restart-Service dhcpserver
```

Authorize both servers in AD. Run on DC01
```powershell
Add-DhcpServerInDC -DnsName "DC01.adlab.test" -IPAddress 192.168.100.10
Add-DhcpServerInDC -DnsName "DC02.adlab.test" -IPAddress 192.168.100.11
```
```powershell
Get-DhcpServerInDC
```
