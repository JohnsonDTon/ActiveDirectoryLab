Create GPO and link to OU. Run on DC
```powershell
New-GPO -Name "Workstations - Auditing"

New-GPLink `
    -Name "Workstations - Auditing" `
    -Target "OU=Workstations,DC=adlab,DC=test"
```

Configure account logon auditing: Track Credential validation <br>
Whenever a user account logs in, logs both success + failure validation (like incorrect pw)
```powershell
Set-GPAuditPolicy `
    -Name "Workstations - Auditing" `
    -Category "Account Logon" `
    -Subcategory "Credential Validation" `
    -Success $true `
    -Failure $true
```

Track Logon sessions, works conjunction with credential validation
```powershell
Set-GPAuditPolicy `
    -Name "Workstations - Auditing" `
    -Category "Logon/Logoff" `
    -Subcategory "Logon" `
    -Success $true `
    -Failure $true
```

Track Logoff sessions
```powershell
Set-GPAuditPolicy `
    -Name "Workstations - Auditing" `
    -Category "Logon/Logoff" `
    -Subcategory "Logoff" `
    -Success $true `
    -Failure $false
```

Configure Account Lockout auditing <br>
Record lockout event to investigate which account was locked and when
```powershell
Set-GPAuditPolicy `
    -Name "Workstations - Auditing" `
    -Category "Logon/Logoff" `
    -Subcategory "Account Lockout" `
    -Success $true `
    -Failure $true
```
