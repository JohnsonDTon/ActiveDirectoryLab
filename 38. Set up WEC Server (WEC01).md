Run this on a fresh (and named) Windows Server VM that you'd making it to be your WEC Server. (refer to Create Windows VM.md) <br>
Make sure the IP/DNS is configured. (refer to Configure IP.md) <br> <br>

This works in conjunction with Event Forwarding GPO, along with Advanced Auditing GPO, PowerShell Logging GPO, and Windows Logging GPO

Join server to domain
```powershell
Add-Computer `
    -DomainName "adlab.test" `
    -Credential "ADLAB\Administrator" `
    -Restart
```

Move server to correct OU. Run on DC.
```powershell
Move-ADObject `
    -Identity "CN=WEC01,CN=Computers,DC=adlab,DC=test" `
    -TargetPath "OU=Member Servers,OU=Servers,DC=adlab,DC=test"
```

Enable WinRM and Event Collector service. Run on WEC01
```powershell
winrm quickconfig -q
wecutil qc /q
```

Raise the ForwardedEvents log to 1 GB so it doesn’t overwrite quickly. Run on WEC01.
```powershell
wevtutil sl ForwardedEvents /ms:1073741824
```

Verify
```powershell
Get-Service WinRM, Wecsvc | Select-Object Name, Status, StartType
```

Create the subscription to watch Security Logons (4624/4625) and PowerShell script blocks (4104).
```powershell
New-Item -Path C:\Temp -ItemType Directory -Force
```
```powershell
@'
<Subscription xmlns="http://schemas.microsoft.com/2006/03/windows/events/subscription">
  <SubscriptionId>Workstation-Security-PowerShell</SubscriptionId>
  <SubscriptionType>SourceInitiated</SubscriptionType>
  <Description>Logons and PowerShell script blocks from Workstations OU</Description>
  <Enabled>true</Enabled>
  <Uri>http://schemas.microsoft.com/wbem/wsman/1/windows/EventLog</Uri>
  <ConfigurationMode>Custom</ConfigurationMode>
  <Delivery Mode="Push">
    <Batching>
      <MaxItems>5</MaxItems>
      <MaxLatencyTime>30000</MaxLatencyTime>
    </Batching>
    <PushSettings>
      <Heartbeat Interval="60000"/>
    </PushSettings>
  </Delivery>
  <Query><![CDATA[
    <QueryList>
      <Query Id="0">
        <Select Path="Security">*[System[(EventID=4624 or EventID=4625)]]</Select>
        <Select Path="Microsoft-Windows-PowerShell/Operational">*[System[(EventID=4104)]]</Select>
      </Query>
    </QueryList>
  ]]></Query>
  <ReadExistingEvents>false</ReadExistingEvents>
  <TransportName>HTTP</TransportName>
  <ContentFormat>RenderedText</ContentFormat>
  <Locale Language="en-US"/>
  <LogFile>ForwardedEvents</LogFile>
  <AllowedSourceNonDomainComputers></AllowedSourceNonDomainComputers>
  <AllowedSourceDomainComputers>O:NSG:NSD:(A;;GA;;;DC)(A;;GA;;;NS)</AllowedSourceDomainComputers>
</Subscription>
'@ | Set-Content C:\Temp\subscription.xml
```
```powershell
wecutil cs C:\Temp\subscription.xml
```

Verify.
```powershell
wecutil gs Workstation-Security-PowerShell
```
