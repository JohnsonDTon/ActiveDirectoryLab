Run this on a fresh (and named) Windows Server VM that you'd making it to be your File Server. <br>
Reference: https://github.com/JohnsonDTon/ActiveDirectoryLab/blob/main/3.%20Create%20VM.md <br>
Make sure the IP/DNS is configured <br>
Reference: https://github.com/JohnsonDTon/ActiveDirectoryLab/blob/main/4.%20Configure%20IP.md <br>

Join FILE01 to domain.
```powershell
Add-Computer `
    -DomainName "adlab.test" `
    -Credential "ADLAB\Administrator" `
    -Restart
```

Install File Server Role
```powershell
Install-WindowsFeature `
    -Name FS-FileServer `
    -IncludeManagementTools
```

Move FILE01 to correct OU. Run this on a DC.
```powershell
$FILE01 = Get-ADComputer "FILE01"
Move-ADObject `
    -Identity $FILE01.DistinguishedName `
    -TargetPath "OU=File Servers,OU=Servers,DC=adlab,DC=test"
```

Create a extra disk for FILE01. Run this on Hyper-V Host. <br>
This disk will be the storage that hold the share files.
```powershell
New-VHD `
    -Path "E:\ActiveDirectoryLab\FILE01\Data.vhdx" `
    -SizeBytes 80GB `
    -Dynamic
```

Attach it to FILE01. Run this on Hyper-V Host.
```powershell
Add-VMHardDiskDrive `
    -VMName "FILE01" `
    -Path "E:\ActiveDirectoryLab\FILE01\Data.vhdx"
```

Verify Disk is attached. Run on FILE01
```powershell
Get-Disk
```

Initialize Disk <br>
New Disk from Get-Disk output is going to be number 1. Check Get-Disk just in case.
```powershell
Initialize-Disk -Number 1 -PartitionStyle GPT
```

Create partition.
```powershell
New-Partition `
    -DiskNumber 1 `
    -UseMaximumSize `
    -DriveLetter E
```

Format the volume
```powershell
Format-Volume `
    -DriveLetter E `
    -FileSystem NTFS `
    -NewFileSystemLabel "FileServerData"
```

Verify
```powershell
Get-Volume
```
