This assumes you configuring server WEC01 after creating this. Will point this GPO to it

Create GPO and link to OU. Run on DC.
```powershell
New-GPO -Name "Workstations - Event Forwarding"

New-GPLink `
    -Name "Workstations - Event Forwarding" `
    -Target "OU=Workstations,DC=adlab,DC=test"
```

Point GPO to WEC01 as Collector.
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Event Forwarding" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\EventLog\EventForwarding\SubscriptionManager" `
    -ValueName "1" -Type String `
    -Value "Server=http://WEC01.adlab.test:5985/wsman/SubscriptionManager/WEC,Refresh=60"
```

Add Network Service account(s) to Event Log Readers. Run on DC
```powershell
Open Group Policy Management
Right click 'Workstations - Event Forwarding' -> Edit...
Computer Configuration
└── Preferences
    └── Control Panel Settings
        └── Local Users and Groups

Right click -> New -> Local Group
Action:      Update
Group name:  Event Log Readers (built-in)
Members -> Add...
    Name:    NT AUTHORITY\NETWORK SERVICE
    Action:  Add to this group
Leave unchecked: Delete all member users, Delete all member groups
Apply
OK
```

Allow the account that forwards the events to read the security logs (so it knows which one to forward)
```powershell
Set-GPRegistryValue `
    -Name "Workstations - Event Forwarding" `
    -Key "HKLM\SOFTWARE\Policies\Microsoft\Windows\EventLog\Security" `
    -ValueName "CustomSD" -Type String `
    -Value "O:BAG:SYD:(A;;0xf0005;;;SY)(A;;0x5;;;BA)(A;;0x1;;;S-1-5-32-573)(A;;0x1;;;S-1-5-20)"
```

Make WinRM start automatically on boot for workstations.
```text
Open Group Policy Management on DC01
Right click 'Workstations - Event Forwarding' -> Edit...
Computer Configuration
└── Policies
    └── Windows Settings
        └── Security Settings
            └── System Services
                └── Windows Remote Management (WS-Management)

Double-click it
Check 'Define this policy setting'
Select: Automatic
Apply
OK
```
