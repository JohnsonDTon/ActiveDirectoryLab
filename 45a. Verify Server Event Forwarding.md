Generate a 4720 and a 4732 on a server (a local test account added to a local group). Run on WSUS01
```powershell
New-LocalUser `
    -Name "wef-test" `
    -NoPassword
```
```powershell
Add-LocalGroupMember `
    -Group "Users" `
    -Member "wef-test"
```
```powershell
Remove-LocalUser `
    -Name "wef-test"
```

Run on WEC01
```powershell
Get-WinEvent `
    -LogName ForwardedEvents `
    -MaxEvents 200 |
    Where-Object Id -in 4720,4732,4726 |
    Select-Object TimeCreated, Id, MachineName
```
