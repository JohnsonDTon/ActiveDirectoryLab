Log into Windows Client machine as a Domain User. <br> <br>

Verify FILE01 is reachable
```powershell
Test-Connection FILE01 -Count 2
```

Verify SMB port (You want TcpTestSucceeded : True)
```powershell
Test-NetConnection FILE01 -Port 445
```

Test Domain User's Access to Share Folder. <br>
This show nothing or contents of Share folder if successful.
```powershell
Get-ChildItem "\\FILE01\IT"
```

Test writing to Share folder
```powershell
"Hello from Alice" | Out-File "\\FILE01\IT\Alice-Test.txt"
```

Verify
```powershell
Get-Content "\\FILE01\IT\Alice-Test.txt"
```
